## Подписаться на новые материалы базы знаний

Изменения в базе знаний вносятся через репозиторий [ruarxive_web](https://github.com/ruarxive/ruarxive_web). Чтобы получать уведомления, нажмите на GitHub **Watch** и выберите нужный уровень уведомлений.
