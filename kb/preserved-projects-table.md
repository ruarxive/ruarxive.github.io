# Сохранённые проекты и коллекции

Найти определённые проекты, отслеживать их статус архивации, а также скачивать их архивы для просмотра и воспроизведения можно с помощью специальной таблицы в AirTable: https://airtable.com/shrO1hise7WgURXg5

Полный перечень файлов в хранилище проекта (с размерами, датами и прямыми ссылками) — в реестре [`allarchives.csv`](https://cdn.ruarxive.org/public/allarchives.csv). Подтверждённые цифры по отдельным коллекциям — на странице [«Статистика: снимок»](/kb/resources/stats-snapshot).

По всем вопросам пишите в Telegram-чат проекта [@ruarxivechat](https://t.me/ruarxivechat).
