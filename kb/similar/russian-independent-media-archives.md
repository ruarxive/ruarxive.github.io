# Российские независимые архивы СМИ

После 2022 года многие независимые российские СМИ были признаны «нежелательными» или «иноагентами» в РФ и переехали за рубеж. Часть из них ведёт собственные архивы, другие — становятся частью партнёрских программ (RIMA, «Архив „Холода“»). Этот материал — карта ресурсов, где исследователь может найти первичные материалы.

> **Предупреждение:** многие СМИ уже не публикуются в РФ; их архивы существуют за счёт грантов и партнёрств. Часть ссылок может быть нестабильной. Всегда проверяйте наличие снимка в [Wayback Machine](https://web.archive.org/).

## Крупные тематические коллекции

### RIMA — Russian Independent Media Archive

[RIMA](https://archive.org/details/russian-independent-media-archive) — партнёрство Internet Archive, Bard College и PEN America, стартовавшее в 2022 году.

| Параметр | Значение |
|:---|:---|
| Покрытие | Крупные независимые СМИ: «Медуза», «Дождь», «Новая газета Европа», «Холод», «Важные истории», IStories и др. |
| Формат | WACZ-коллекции на archive.org, доступ через ReplayWeb.page |
| API | Стандартный CDX API архива IA |
| Обновление | Ежемесячно (по плану), критические события — чаще |
| Стоимость | Бесплатно |

Доступ:

```
https://archive.org/details/russian-independent-media-archive
https://web.archive.org/cdx/search/cdx?url=meduza.io/*&matchType=domain&filter=statuscode:200
```

> **Ruarxive и RIMA:** для архивов, попавших в обе коллекции, рекомендуемое поведение — двойная загрузка (копия в RIMA, копия в Ruarxive). Это страхует от потери одной из инфраструктур.

### PEN America — Russian Independent Media Archive (детали)

Содержательная часть — статьи, посты, видео-интервью, подкасты. Структура по изданиям, языки RU/EN.

### «Архив „Холода"»

[«Холод»](https://holod.media/) — независимое медиа, ведущее собственный открытый архив собственных материалов.

| Параметр | Значение |
|:---|:---|
| Покрытие | Собственные материалы «Холода» |
| Доступ | Через сайт, через archive.org |
| Особенность | Часть эксклюзивных расследований хранится только в собственном архиве |
| Контакт | `archive@holod.media` |

### «Медуза»

«Медуза» [meduza.io](https://meduza.io/) — крупнейшее независимое СМИ в эмиграции.

| Параметр | Значение |
|:---|:---|
| Покрытие | Все материалы meduza.io с 2014 года |
| Доступ | Через сайт, через archive.org |
| Особенности | Часть материалов доступна только подписчикам; сохраняются публичные версии |

Поиск в Wayback Machine:

```bash
curl 'https://web.archive.org/cdx/search/cdx?url=meduza.io/*&matchType=domain&filter=mimetype:text/html&output=json&limit=20'
```

### «Новая газета — Европа»

[novayagazeta.eu](https://novayagazeta.eu/) — продолжатель традиций «Новой газеты».

| Параметр | Значение |
|:---|:---|
| Покрытие | Материалы с 2022 |
| Доступ | Сайт + архивы |
| Связь | Часть архивов «Новой газеты» (Москва, 1993–2022) — в специальных коллекциях |

### «Дождь» (Dozhd)

[tvrain.ru](https://tvrain.ru/) / [youtube.com/@tvrainru](https://www.youtube.com/@tvrainru) — видео-архив.

Для видео-архива «Дождя» используется [yt-dlp](https://github.com/yt-dlp/yt-dlp):

```bash
# Скачать выпуск новостей
yt-dlp 'https://www.youtube.com/watch?v=ID_ВИДЕО'
```

### IStories / «Важные истории»

[istories.media](https://istories.media/) — расследовательский проект. Архив расследований хранится самостоятельно + дублируется в RIMA.

### «Медуза» + «Батенька, у нас проблемы» + «Новая»

Эти и другие издания образуют «ядро» RIMA. Общий объём — десятки тысяч материалов ежемесячно.

## Что делать, если нужного архива нет

### Шаг 1. Проверить Wayback Machine

```bash
curl 'https://archive.org/wayback/available?url=имя.сайта/&timestamp=20240601'
```

Если есть — сохраните URL архива.

### Шаг 2. Проверить Memento Aggregator

```bash
curl 'https://timetravel.mementoweb.org/api/json/20240601/https://имя.сайта/'
```

Покажет, в каких архивах вообще есть материал.

### Шаг 3. Проверить RIMA-подобные коллекции

Часть изданий входит в [RIMA](https://archive.org/details/russian-independent-media-archive). Если есть — архив уже организован.

### Шаг 4. Написать в редакцию

Большинство независимых СМИ в эмиграции благодарны за архивирование. Стандартный контакт — `archive@` или `press@`. Укажите:

- что именно хотите сохранить (URL, диапазон дат, тему);
- для чего (исследование, проект, публикация);
- что готовы делать сами (зеркалирование, проверка, метаданные).

### Шаг 5. Загрузить в RIMA или Ruarxive

Если материала нет нигде — это сигнал для архивиста:

1. Загрузить в [RIMA через Internet Archive](https://archive.org/details/russian-independent-media-archive) — там работают редакторы и принимают материалы по договорённости.
2. Создать запись в [Airtable Ruarxive](https://airtable.com/shrO1hise7WgURXg5) для собственного архива.
3. Использовать [wparc](https://github.com/ruarxive/wparc) или [tgarc](https://github.com/ruarxive/tgarc) для сбора.

## Специфика архивации в условиях РФ

- **Юридические риски.** Независимые СМИ признаны «нежелательными» / «иноагентами»; хранение их материалов на серверах в РФ — потенциальный риск. Всегда выбирайте хостинг вне РФ для публичного архива.
- **Анонимизация источников.** Если в материалах есть имена авторов — это утечка их идентичности. Не распространяйте без согласования.
- **Доступ к редакционным материалам.** Часть эксклюзивных материалов (расследования, документы) доступна только подписчикам — архивирование без согласия авторов считается нарушением. Решение: «открытая часть + ссылка на archive.org для платной».
- **Безопасность исследователей.** Если вы изучаете чувствительные темы (война, репрессии), не храните метаданные на личных устройствах.

## Рекомендации для исследователя

1. **Дублируйте доступы.** Ключевые архивы держите в нескольких местах: archive.org, Ruarxive, локально, на S3.
2. **Фиксируйте даты.** Сохраняйте `WARC-Target-Date` метаданные — статья на ту же тему через год может иметь другую редакцию.
3. **Проверяйте версии.** Статья могла быть отредактирована. Wayback Machine помогает найти первую редакцию.
4. **Сохраняйте «соседей».** При исследовании конкретной статьи сохраняйте заглавную страницу издания и материалы по той же теме — для контекста.

## Юридическая оговорка

> [!WARNING]
> Часть изданий признана «нежелательными» / «иноагентами» в РФ. Хранение и распространение их материалов на территории РФ может повлечь ответственность. Архивирование для исследовательских, журналистских или образовательных целей за пределами РФ, как правило, законно и поддерживается редакциями. Подробнее — [Правовые вопросы](/kb/legal/copyright).
