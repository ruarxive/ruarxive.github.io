# Каталоги «Awesome…» для архивистов

Тематические **«Awesome»-списки** в GitHub — это популярный формат для каталогизации ресурсов по конкретной теме. Для цифровой архивации есть несколько высококачественных списков.

## Зачем сюда заглядывать

- **Следить за инструментарием** — появляются новые утилиты, форматы, фреймворки.
- **Находить тематические сообщества** — Reddit-треды, рассылки, Slack-каналы.
- **Подсматривать успешные практики** — чек-листы, методологии, шаблоны.
- **Найти партнёрства** — международные контакты по близким темам.

## Основные списки

### [awesome-web-archiving](https://github.com/iipc/awesome-web-archiving)

Курируется International Internet Preservation Consortium (IIPC). Включает:

- инструменты (wget, Browsertrix, Heritrix);
- форматы (WARC, WACZ, CDXJ);
- академические работы и стандарты;
- сообщества и конференции.

### [awesome-digital-preservation](https://github.com/mbtaylor/awesome-digital-preservation)

Более широкий список — выходит за рамки веб-архивации: аудио/видео-форматы, цифровое искусство, файловые системы.

### [awesome-digital-humanities](https://github.com/dh-tech/awesome-digital-humanities)

Цифровые гуманитарные науки с акцентом на методологии и инструменты.

### [awesome-open-data](https://github.com/awesomedata/awesome-open-data)

Открытые данные: источники, инструменты анализа, дашборды.

### [awesome-government-data](https://github.com/jgoerner/awesome-government-data)

Открытые государственные данные по темам.

## Другие полезные каталоги

### [Digital Archiving Resources](https://diglib.org/archives/digitalarchives/)

Подборка ресурсов от Library of Congress.

### [Web Archiving Community List](https://web.archive.org/web/)

Список сообществ из Internet Archive.

### [Open Source Archiving](https://github.com/openpreserve/open-source-archiving)

Все Open Source проекты вокруг digital preservation.

## Как пользоваться

> [!TIP]
> Эти списки обновляются сообществом. При поиске **новых** инструментов (после 2024 года) проверяйте дату последнего коммита.

Типичная стратегия:

1. Нашёл интересный инструмент → копируете описание и ссылки.
2. Ищете контекст использования в 2–3 крупных проектах.
3. Добавляете в свою внутреннюю wiki / project knowledge base.
