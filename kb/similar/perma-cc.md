# Perma.cc

[Perma.cc](https://perma.cc/) — сервис долгосрочного цитирования веб-страниц,
созданный в 2013 году Гарвардской библиотекой. Используется академическим и юридическим
сообществом для борьбы с «ссылочным распадом» (link rot).

## Как работает

1. Юзер создаёт учётную запись (только академические и юридические организации).
2. Сохраняет URL через [perma.cc](https://perma.cc/).
3. Получает постоянную ссылку вида `https://perma.cc/XXXX-YYYY`.
4. Цитирует эту ссылку вместо оригинальной.

## Отличие от Wayback Machine

- **Perma.cc** — создаётся вручную для конкретных нужд цитирования. Архивируется только
  та версия страницы, которая была сохранена.
- **Wayback Machine** — массовый автоматический сбор, пользователь видит «любую»
  историческую версию.

## Преимущества Perma.cc

- **Юридическая устойчивость** — ссылки принимаются судами как доказательства.
- **Контролируемая выборка** — нет «неожиданных» изменений страницы.
- **Академический фокус** — узкая ниша цитирования, не массовый архив.

## Когда использовать

- Научные статьи и диссертации.
- Юридические документы и заключения.
- Деловая переписка, где важна точность формулировок.

## Ruarxive и Perma.cc

Ruarxive фокусируется на архивации **под угрозой** — Perma.cc — на **цитировании**.
Это разные ниши, дополняющие экосистему цифровой памяти.

## Лицензия

Сервис предоставляется бесплатно для академических и юридических организаций.
Доступ к архивам — открытый по запросу.
