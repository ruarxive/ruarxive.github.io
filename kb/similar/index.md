# Открытые архивные сервисы — карта

Ruarxive — не единственный проект в области веб-архивации. Этот раздел собран как **карта открытых сервисов**, к которым можно обращаться за архивами или в которые можно передавать свои материалы. Ниже — оперативная карта «куда и зачем», а в конце страницы — ссылки на подробные обзоры.

## Сравнительная таблица

| Сервис | Тип | Главное | Доступ | Когда использовать |
|:---|:---|:---|:---|:---|
| **Internet Archive / Wayback Machine** | Массовый веб-архив | Более 1 трлн сохранённых страниц (отметка пройдена в октябре 2025 года), с 1996 года | Публичный, бесплатный | Долгосрочное хранение, поиск исчезнувших страниц |
| **Common Crawl** | Открытые веб-краулы | Ежемесячные краулы по ~2 млрд страниц в WARC/WAT/WET | Бесплатная выгрузка | Исследования, корпуса текстов, анализ веба |
| **Perma.cc** | Постоянные ссылки для цитирования | Сохранение страницы по запросу пользователя, ссылка вида `perma.cc/XXXX-XXXX` | Бесплатно через библиотеки-партнёры и суды; для остальных — 10 пробных ссылок, затем платная подписка | Научные и юридические публикации |
| **Archive.today** (archive.ph, archive.is) | Моментальные снимки | 1 URL → 1 снимок; в 2026 году оператор менял сохранённые снимки, Википедия отказалась от ссылок на сервис | Бесплатный | Только дополнительная копия; поиск старых снимков, которых нет в Wayback Machine ([подробнее](/kb/instruments/tools/archive-ph)) |
| **Archive-It** (Internet Archive) | Курируемая архивация | Сервис веб-архивации для библиотек и организаций | По подписке | Институциональные коллекции |
| **ArchiveTeam** | Волонтёрское движение | Экстренная архивация закрывающихся сервисов | Открытый | Когда сервис закрывается |
| **Национальные веб-архивы** (UK Web Archive, BnF, Arquivo.pt, Australian Web Archive и др.) | Государственные программы | Архивация национального сегмента веба | Через сайты национальных библиотек и архивов | Изучение конкретной страны |

:::note Conifer
Сервис Conifer (Rhizome) с мая 2026 года не принимает новые захваты: существующие коллекции доступны только для просмотра. Для новых захватов используйте [Browsertrix](/kb/instruments/tools/browsertrix) или расширение ArchiveWeb.page.
:::

## Когда что использовать

### «Где хранить свой WARC?»

| Приоритет | Вариант | Почему |
|:-:|:---|:---|
| 1 | **Собственное хранилище** (локально + облако) | Контроль над данными, офлайн-страховка |
| 2 | **Internet Archive** | Глобальный доступ, долгосрочное хранение; загрузка открыта любому зарегистрированному пользователю |
| 3 | **Kiwix (warc2zim)** | Если нужно распространять как офлайн-библиотеку |

Если архив общественно значим для российского контекста, напишите в [чат Ruarxive](https://t.me/ruarxivechat) — открытого приёма загрузок у проекта нет, но вопрос хранения можно обсудить.

### «Откуда достать чужой архив?»

| Задача | Сервис |
|:---|:---|
| Страница правительственного сайта | Internet Archive (CDX API), национальные веб-архивы |
| Данные для исследований веба и языковых моделей | Common Crawl |
| Ссылка для научной или юридической публикации | Perma.cc |
| Сайт, который только что закрылся | ArchiveTeam Wiki, Internet Archive |
| Поиск снимков сразу в нескольких архивах | [Memento](/kb/instruments/replay/memento), расширение [PastPage](/kb/instruments/tools/pastpage) |

### «Найти данные о конкретной платформе»

| Платформа | Где искать |
|:---|:---|
| Telegram | Публичные каналы — веб-версия `t.me/s/имя_канала` в Wayback Machine; собственные выгрузки — [tgarc](/kb/instruments/ruarxive-tools/tgarc) |
| Twitter/X | Internet Archive, Bellingcat Auto-Archiver |
| Государственные сайты | Национальные веб-архивы, Internet Archive |
| Видео | yt-dlp + собственный архив |

## Принципы выбора

1. **Не зависьте от одного сервиса.** Правило 3-2-1 для важных архивов: 3 копии, на 2 разных носителях, 1 — в другом месте.
2. **Проверяйте условия использования** перед массовой выгрузкой с чужого сервиса.
3. **При публикации** указывайте лицензию только на то, на что у вас есть права: лицензия загрузчика не распространяется на чужой контент.
4. **Для собственных архивов** — собственный сервер воспроизведения (pywb) и копия в Internet Archive.
