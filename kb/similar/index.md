# Открытые архивные сервисы — карта

Ruarxive — не единственный проект в области веб-архивации. Этот раздел собран как **карта открытых сервисов**, к которым можно обращаться за архивами или на которые можно лить свои материалы.

Подробный список публикаций и инициатив — в [Похожих проектах](/kb/similar). Здесь — оперативная карта «куда и зачем».

## Сравнительная таблица

| Сервис | Тип | Главное | Доступ | Язык | Когда использовать |
|:---|:---|:---|:---|:---|:---|
| **Internet Archive / Wayback** | Массовый веб-архив | 800+ млрд страниц с 1996 | Публичный бесплатный | Преимущественно EN | Долгосрочное хранение, международный контент |
| **RIMA** (Russian Independent Media Archive) | Тематическая коллекция IA | Российские независимые СМИ | Через IA | RU/EN | Исследования современной России |
| **Common Crawl** | Сырые веб-краулы | Петабайты HTML, метаданные | Бесплатный bulk download | Мульти | ML-исследования, языковые модели |
| **Perma.cc** | Цитирование веб-страниц | Юридически-значимые постоянные ссылки | Бесплатно для академических/юридических org | EN | Научные работы, юридические документы |
| **Archive.today** (archive.is, archive.ph) | Моментальные снимки | 1 URL → 1 постоянная ссылка | Бесплатный | Мульти | «Снимок прямо сейчас» без регистрации |
| **Archive-It** (Internet Archive) | Курируемая архивация | Workflow номинация→архивация для библиотек | По подписке | EN | Библиотеки, институциональные проекты |
| **Conifer (Rhizome)** | Self-hosted replay | Личный архив на pywb | Self-host | EN | Личный архив с галерейным UI |
| **ArchiveTeam** | Волонтёрское движение | Экстренные краулы под угрозой закрытия | Открытый | EN | Когда сервис закрывается — спасение |
| **archive.org.ua, archivalia** | Региональные архивы | Украинский сегмент веба | Публичный | UK/RU | Региональные исследования |
| **Национальные архивы (BARD, BnF, KB)** | Государственные программы | Курируемая архивация национального веб-домена | Через сайт нац. библиотеки | Локальный | Для изучения конкретной страны |

## Когда что использовать

### «Куда залить свой WARC?»

| Приоритет | Сервис | Почему |
|:-:|:---|:---|
| 1 | **Ruarxive** (локально) | Контроль над данными, оффлайн-страховка |
| 2 | **Internet Archive** | Глобальный доступ, гарантия длинного хранения |
| 3 | **Kiwix (warc2zim)** | Если нужно распространять как оффлайн-энциклопедию |

### «Откуда достать чужой архив?»

| Задача | Сервис |
|:---|:---|
| Страница правительственного сайта | Internet Archive (CDX API), Memento Aggregator |
| Данные для обучения LLM | Common Crawl |
| Юридически значимая ссылка | Perma.cc |
| Сайт, который только что закрылся | ArchiveTeam wiki, Internet Archive |

### «Найти данные о конкретной платформе»

| Платформа | Где искать |
|:---|:---|
| Telegram (3.7 млрд страниц) | Internet Archive → collection `telegram` |
| Twitter | Internet Archive, Bellingcat Auto-Archiver |
| Государственные сайты | Национальные архивы, Internet Archive по стране |
| Видео | yt-dlp + локальный архив, archive.today |

## Принципы выбора

1. **Не зависьте от одного сервиса.** Правило 3-2-1 для важных архивов: 3 копии, на 2 разных носителях, 1 — вне офиса.
2. **Проверяйте лицензию** перед массовой загрузкой с чужого сервиса.
3. **Для публикации** предпочтительны открытые лицензии (CC0, CC-BY).
4. **Для собственных архивов** — собственный сервер (pywb) + копия на IA + Ruarxive.
