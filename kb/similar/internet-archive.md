# Internet Archive

[Internet Archive](https://archive.org/) — некоммерческая библиотека, основанная
Брюстером Кейлом в 1996 году. Это крупнейший в мире веб-архив, включающий Wayback Machine,
текстовые книги, аудио, видео и программное обеспечение.

## Wayback Machine

Главный инструмент Internet Archive — [Wayback Machine](https://web.archive.org/),
позволяющий просматривать сохранённые версии веб-страниц. По состоянию на 2024 год
содержит более 800 миллиардов веб-страниц.

## Save Page Now

Любой пользователь может сохранить страницу через
[web.archive.org/save](https://web.archive.org/save/). Страница становится доступной
постоянно, если не поступит обоснованный takedown-запрос.

## API

Internet Archive предоставляет открытый [Wayback Machine API](https://archive.org/help/wayback_api.php),
позволяющий программно сохранять и запрашивать снимки страниц.

## Ruarxive и Internet Archive

Часть архивов Ruarxive загружается в Internet Archive. Например:

- [Коллекция Ruarxive на Internet Archive](https://archive.org/details/@ruarxive)
- [Echo of Moscow](https://archive.org/details/echo-of-moscow)

Это создаёт дополнительную страховку: данные хранятся в двух независимых инфраструктурах.

## Ограничения

- Охват ограничен популярными ресурсами (по критериям цитируемости).
- Не всегда сохраняет медиа и интерактивные элементы.
- Периодически блокируется на территории РФ.

## Когда использовать

- Глобальные ресурсы и международные СМИ.
- Долгосрочное хранение (Internet Archive работает с 1996 года).
- Когда нужно восстановить давно исчезнувший сайт.
