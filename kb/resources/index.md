# Ресурсы

В этом разделе собраны справочные материалы, которые не вписываются в
гайды и кейсы, но нужны при работе с архивами: текущая статистика
Ruarxive, тестовые наборы WARC, реестры форматов, сравнительные таблицы
инструментов.

## Что внутри

- [Снимок статистики](/kb/resources/stats-snapshot) — актуальные цифры по архивам Ruarxive (проверено 2026-10-07).
- [Статистика по годам](/kb/resources/statistics) — сводные данные по проектам, типам контента и росту коллекции.
- [Сравнения инструментов](/kb/resources/comparisons) — таблицы «что лучше подходит для какой задачи».
- [Тестовые файлы](/kb/resources/test-files) — небольшие WARC/WACZ/CDX для отладки пайплайнов и проверки инструментов.

## Как пользоваться

Если вы только начинаете работать с архивами — начните со
[снимка статистики](/kb/resources/stats-snapshot), чтобы понять масштаб задачи. Затем
перейдите к [сравнениям](/kb/resources/comparisons), чтобы выбрать подходящий
инструмент. Для разработчиков полезен раздел [тестовых файлов](/kb/resources/test-files):
на них удобно проверять новые версии WARC-парсеров.
