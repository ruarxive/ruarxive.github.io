# Статистика Ruarxive: снимок

Это каноническая страница со статистикой проекта: другие страницы базы знаний ссылаются на неё. Здесь приведены **только подтверждённые цифры по отдельным коллекциям** — у каждой указаны источник и дата. Общий объём архива и общее число проектов не приводятся: единого пересчёта по всем коллекциям пока нет.

Последняя сверка страницы: **12.10.2026**. Ссылки вида `#N` ведут на публикации канала [@ruarxive](https://t.me/ruarxive).

## Исторические цифры

Эти цифры относятся к своему времени и не описывают текущий архив:

- **21.01.2017** — проект «Архивация государства»: «уже собрано несколько терабайт данных в сжатом виде и десятков-сотен в распакованном» ([@begtin](https://t.me/begtin/397)).
- **24.01.2017** — 1,4 ТБ веб-архивов, около 15 ТБ в распакованном виде, в том числе 345 сайтов банков и около 500 сайтов органов власти ([@begtin](https://t.me/begtin/402)).

Цифры из слайдов курса DH.1–DH.4 относятся к дате лекций и здесь не учитываются.

## Собственные инструменты

Инструменты с открытым кодом, которые развивает проект и его участники:

- [tgarc](/kb/instruments/ruarxive-tools/tgarc) — архивация Telegram-каналов (не развивается с декабря 2023 года, для нового сбора — [tdl](/kb/instruments/tools/tdl));
- [wparc](/kb/instruments/ruarxive-tools/wparc) — сайты на WordPress через REST API;
- [ydiskarc](/kb/instruments/ruarxive-tools/ydiskarc) — публичные папки Яндекс.Диска;
- [filegetter](/kb/instruments/ruarxive-tools/filegetter) — массовое скачивание файлов по спискам;
- [apibackuper](/kb/instruments/downloaded-data/apibackuper) — архивация REST API;
- [spcrawler](/kb/instruments/downloaded-data/spcrawler) — публичные сайты на SharePoint;
- [metawarc](/kb/instruments/ruarxive-tools/metawarc) — индексация и анализ WARC.

## Как обновлять эту страницу

1. Добавляйте только цифры, у которых есть источник: публикация в канале, файл в хранилище (`cdn.ruarxive.org`) или запись в реестре [`allarchives.csv`](https://cdn.ruarxive.org/public/allarchives.csv).
2. Указывайте дату, на которую цифра верна.
3. Не суммируйте коллекции в «общий объём» без полного пересчёта по хранилищу.
4. Обновите `last_updated` и дату сверки в начале страницы.
