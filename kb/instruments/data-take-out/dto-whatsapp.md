# Как сохранить данные из WhatsApp

У WhatsApp нет полной выгрузки переписки одним архивом. Сообщения защищены сквозным шифрованием и хранятся на устройствах пользователей, поэтому сохранять их приходится по одному чату. Ниже — официальные способы и их ограничения.

## Когда стоит архивировать WhatsApp

- **Семейные чаты и чаты сообществ**, которые могут быть удалены участниками.
- **Фиксация переписки** — например, для журналистской работы или юридических целей.
- **Каналы WhatsApp**, которые могут исчезнуть.

## 1. Экспорт отдельного чата

Основной способ сохранить сообщения. Экспорт содержит историю чата, которая есть на вашем устройстве, — включая сообщения собеседников и участников группы.

По [справке WhatsApp](https://faq.whatsapp.com/1180414079177245/?locale=ru_RU) (Android):

1. Откройте чат.
2. Нажмите «Другие опции» (три точки) → «Ещё» → «Экспорт чата».
3. Выберите «Без медиафайлов» или «Добавить файлы».
4. Выберите, куда отправить экспорт: по электронной почте, в мессенджер, в заметки или файловое хранилище.

На iPhone экспорт запускается из сведений о контакте или группе («Экспорт чата»).

**Что получится:** текстовый файл `.txt` с историей и, если выбрано «Добавить файлы», недавние медиафайлы вложениями.

**Ограничения:**

- В версиях справки 2023–2024 годов WhatsApp указывал, что с медиафайлами можно экспортировать до 10 000 последних сообщений, без медиа — до 40 000 сообщений (из-за ограничений размера электронного письма). В текущей справке эти цифры не приводятся, поэтому для длинных чатов проверяйте, что экспорт начинается с самого первого сообщения.
- При экспорте с файлами добавляются только недавние медиафайлы.
- Экспорт нельзя импортировать обратно в WhatsApp — это текстовый файл, а не резервная копия.
- Удалённые сообщения в экспорт не попадают.

## 2. Запрос информации аккаунта

В разделе «Настройки» → «Аккаунт» → «Запрос информации аккаунта» можно запросить отчёт об аккаунте.

:::warning Сообщений в этом отчёте нет
По [справке WhatsApp](https://faq.whatsapp.com/526463418847093/?locale=ru_RU), отчёт содержит информацию и настройки аккаунта, но **не содержит ваших сообщений**, информации о каналах и рекламе. Для сохранения переписки используйте экспорт чатов.
:::

- Отчёт готов примерно через 3 дня; после этого его нужно скачать в ограниченный срок, затем он удаляется с серверов WhatsApp.
- Запросить отчёт в приложениях WhatsApp для Windows и Mac нельзя — используйте телефон или WhatsApp Web.
- Отдельно можно запросить отчёт о каналах и отчёт о рекламе.

## 3. Резервные копии

WhatsApp умеет создавать резервные копии чатов: на Android — в Google Диске, на iPhone — в iCloud («Настройки» → «Чаты» → «Резервная копия чатов»). Резервная копия нужна для восстановления переписки в WhatsApp на новом устройстве, а не для чтения в других программах:

- локальные резервные копии на Android зашифрованы (файлы `.crypt12`, `.crypt14`, `.crypt15`). Расшифровать их можно открытым инструментом [wa-crypt-tools](https://github.com/ElDavoo/wa-crypt-tools), но для этого нужен ключ: файл ключа с устройства или 64-символьный ключ сквозного шифрования резервной копии.

## 4. WhatsApp Web

Переписку можно просматривать и сохранять вручную (скриншоты, копирование) через [WhatsApp Web](https://web.whatsapp.com/). Автоматический сбор через WhatsApp Web запрещён условиями использования и может привести к блокировке аккаунта.

## Каналы WhatsApp

У каналов WhatsApp нет публичного API для выгрузки. Варианты:

- подписаться на канал и сохранять публикации вручную;
- попросить администратора канала сохранить материалы;
- исследователям — искать публикации каналов через [Meta Content Library](https://transparency.meta.com/researchtools/meta-content-library) (доступ по заявке для академических и некоммерческих организаций).

## Что выбрать

| Метод | Что сохраняется | Когда |
|:---|:---|:---|
| Экспорт чата | Сообщения одного чата (с ограничениями по объёму) и недавние медиа | Основной способ сохранить переписку |
| Отчёт об информации аккаунта | Данные и настройки аккаунта, без сообщений | Сведения о собственном аккаунте |
| Резервная копия | Вся переписка на момент копирования, для восстановления в WhatsApp | Перенос на новое устройство |
| WhatsApp Web вручную | То, что видно на экране | Фиксация отдельных сообщений |

## Сценарии

### Семейный архив

Экспортируйте важные чаты с медиафайлами по одному, храните полученные `.txt` и файлы вместе с описанием: чей чат, когда выгружен.

### Журналистская фиксация переписки

Экспорт чата, скриншоты ключевых сообщений, контрольные суммы (SHA-256) полученных файлов и запись о том, когда и кем выполнен экспорт. Если фиксация нужна для суда, проконсультируйтесь с юристом о нотариальном заверении — сохранение в веб-архивах вроде Perma.cc им не является.

## Юридические аспекты

:::warning
Условия использования WhatsApp запрещают автоматический сбор данных. Перед архивацией учитывайте:

- цель архивирования (личная, журналистская, исследовательская);
- что в переписке содержатся [персональные данные](/kb/legal/personal-data) других людей;
- есть ли у вас право распространять архив.
:::

Подробнее: [Правовые вопросы](/kb/legal/copyright).

## Хранение архива

Пример структуры каталога:

```
whatsapp-archive-2026/
├── chats/
│   ├── chat-friend-a/
│   │   ├── chat.txt
│   │   └── media/
│   └── chat-group-x/
├── account-report/   # отчёт об информации аккаунта
├── checksums.sha256
└── README.md         # контекст, даты, разрешения
```
