# Как сохранить данные из Facebook

Facebook позволяет экспортировать копию своих данных с помощью инструмента «Экспорт информации» (Export your information). Сейчас он находится в настройках аккаунта Meta («Центр аккаунтов» / Meta Account); старый адрес [facebook.com/dyi](https://www.facebook.com/dyi/) ведёт туда же.

## Шаг 1: Запуск экспорта

По [справке Facebook](https://www.facebook.com/help/212802592074644):

1. Нажмите на фото профиля → «Настройки и конфиденциальность» → «Настройки».
2. Откройте «Аккаунт Meta» (или «Центр аккаунтов») → «Ваша информация и разрешения».
3. Выберите «Экспорт информации» → «Создать экспорт».
4. Выберите профиль и способ: **на устройство** или **во внешний сервис** (облачное хранилище, с возможностью регулярного экспорта).

## Шаг 2: Выбор формата и данных

*   **HTML** — для чтения человеком: архив содержит файл `index.html`, который открывается в браузере.
*   **JSON** — машиночитаемый формат для анализа и переноса в другие сервисы.

![Data take out Facebook: formats](/images/image1.png)

Можно выгрузить всё или выбрать отдельные категории, указать диапазон дат и **качество медиафайлов** (высокое качество заметно увеличивает размер архива). Среди категорий:

*   публикации и публикации, в которых вас отметили;
*   комментарии и реакции;
*   сообщения (личная переписка и групповые чаты);
*   друзья и подписчики;
*   группы, мероприятия, страницы, которыми вы управляете;
*   история входов и сведения о безопасности;
*   информация о рекламе.

![Data take out Facebook: type of information](/images/image4.png)

## Шаг 3: Ожидание и загрузка

*   Когда архив будет готов, придут уведомление в Facebook и письмо на выбранный адрес.
*   **Скачать архив можно в течение 4 дней** в разделе «Доступные файлы» инструмента «Экспорт информации»; затем его нужно запрашивать заново.
*   Для скачивания потребуется ввести пароль.
*   Большой архив приходит в виде нескольких ZIP-файлов.

## Ограничения

*   **Деактивированный профиль** нужно сначала активировать; профиль, запланированный к удалению, — восстановить, отменив удаление.
*   **Удалённый профиль** выгрузить нельзя.
*   **Сторонние приложения** хранят данные у себя, и в выгрузку они не попадают.
*   **Удалённые публикации** в архив не включаются.
*   **Дополнительные профили:** часть данных (например, о рекламе) доступна только при экспорте основного профиля.

## Альтернативы

*   [Browsertrix](/kb/instruments/tools/browsertrix) с авторизованным браузерным профилем — для публичных страниц и групп.
*   [Wayback Machine](/kb/instruments/tools/wayback-api) — если публичная страница ранее попала в веб-архив.

Получить через API данные удалённого или чужого аккаунта нельзя. Устаревший инструмент [F(b)arc](/kb/instruments/social-media/fbarc) (в архиве с 2018 года) работал только с публичными данными через Graph API.
