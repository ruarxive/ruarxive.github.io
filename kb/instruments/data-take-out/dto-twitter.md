# Как сохранить данные из Twitter (X)

Скачивание архива своих данных из Twitter (X) доступно в настройках
пользователя по адресу [twitter.com/settings/download_your_data](https://twitter.com/settings/download_your_data)
(для X — [x.com/settings/download-your-data](https://x.com/settings/download-your-data)).

## Что входит в архив

Можно запросить ZIP-файл с архивом следующих сведений:

*   **Учётная запись**: имя пользователя, e-mail, телефон, история смены пароля.
*   **Информация профиля**: bio, аватар, баннер, локация.
*   **Твиты**: все ваши публикации, ретвиты, ответы, лайки.
*   **Личные сообщения (DM)**: текст, медиа, ссылки (если не удалены).
*   **Медиафайлы**: загруженные изображения, видео, GIF.
*   **Списки**: ваши списки и подписки.
*   **Предполагаемые интересы** и **демографическая информация** (на основе алгоритмов Twitter).
*   **Рекламные данные**: история взаимодействия с рекламными объявлениями.
*   **Журналы**: история входов, история поиска, события безопасности.

## Формат

Полученный архив данных будет доступен для загрузки в **HTML** и **JSON**
форматах:

*   **HTML** — для просмотра в браузере, удобно для разовых проверок.
*   **JSON** — для программной обработки и импорта в Ruarxive.

## Сроки

*   Подготовка архива занимает **от нескольких часов до 1–2 дней**
  в зависимости от объёма аккаунта.
*   Ссылка на скачивание приходит в приложение и на привязанный e-mail.
*   Срок жизни ссылки — **30 дней**, после чего нужно запрашивать заново.

## Ограничения

*   **Удалённые твиты не восстанавливаются** — в архиве только то, что
  осталось на момент запроса.
*   **Аккаунт должен быть активен** — после удаления/блокировки
  официальный канал выгрузки не работает.
*   **DM-сообщения от удалённых пользователей** могут отсутствовать.

## Альтернативы для удалённых/заблокированных аккаунтов

*   [twarc](/kb/instruments/social-media/twarc) — если у вас есть
  Academic Research API доступ.
*   [Браузерная архивация](/kb/instruments/tools/browsertrix) с
  авторизованным профилем — для публичных аккаунтов.
*   Локальный кэш, собранный в процессе мониторинга.
