# Notion

Notion позволяет экспортировать данные всего рабочего пространства
или отдельных страниц. Это критически важно для сохранения рабочих
заметок, документации проектов и баз знаний, потому что **Notion не
предоставляет локального бэкапа** — все данные хранятся на серверах.

## Полный экспорт Workspace

1.  Перейдите в **Settings & Members** (Настройки и участники).
2.  Выберите **Settings** (Настройки).
3.  Прокрутите вниз до раздела **Export content** (Экспорт контента).
4.  Нажмите **Export all workspace content**.

### Настройки экспорта

*   **Export format**:
    *   **Markdown & CSV** — наиболее универсальный формат.
    *   **HTML** — сохраняет визуальное представление.
    *   **PDF** — подходит только для печати/чтения, не для миграции.
*   **Include subpages**: Включено (для полного бэкапа).
*   **Include databases**: Включено (базы экспортируются как CSV).
*   **Create folders for subpages**: Включено (сохраняет иерархию).
*   **Export page content as comments**: выберите, если нужны комментарии.

Вы получите ссылку на скачивание ZIP-архива на почту. Ссылка живёт
**30 дней**.

## Экспорт отдельной страницы

1. Откройте нужную страницу.
2. Нажмите **•••** в правом верхнем углу.
3. Выберите **Export** (или **Export to PDF** для PDF).
4. Укажите формат и диапазон (только эта страница / с подстраницами).

## Что попадает в архив

*   Страницы и подстраницы с форматированием.
*   Базы данных — каждая таблица как отдельный CSV-файл.
*   Загруженные файлы и изображения (в подпапке).
*   Комментарии (опционально).
*   Свойства страниц (Properties).
*   Аватары пользователей.

## Ограничения

*   **Комментарии экспортируются, но могут быть трудночитаемыми**
  вне интерфейса Notion.
*   **Связи баз данных (Relations)** превращаются в текстовые ссылки
  или теряются — для восстановления нужна отдельная обработка.
*   **Rollup-поля** и **Formula-поля** экспортируются как вычисленные
  значения, без формул.
*   **Синхронизированные блоки** дублируются в местах вставки.
*   **Permissions (права доступа)** не сохраняются — все страницы
  становятся «публичными» в архиве.
*   **OAuth-интеграции** в архив не попадают.

## Регулярный бэкап

Notion официально не предоставляет API для регулярных выгрузок, но
существует несколько обходных путей:

*   **Notion API** ([developers.notion.com](https://developers.notion.com/))
  — для интегрированных страниц можно выгружать содержимое программно.
*   **Сторонние инструменты**:
    *   [notion-backup](https://github.com/drichardson/notion-backup) —
      Python-скрипт, использующий официальный API.
    *   [archivelator](https://github.com/rastislav/archivelator) — для
      Notion-совместимых API-сервисов.
