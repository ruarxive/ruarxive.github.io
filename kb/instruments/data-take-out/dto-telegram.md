# Как сохранить данные из Telegram

Чтобы скачать данные из конкретных Telegram-каналов и чатов, необходимо
воспользоваться версией [Telegram Desktop](https://desktop.telegram.org/).

## Способ 1: Через интерфейс Telegram Desktop

1. Откройте нужный канал или чат.
2. Нажмите на «три точки» в правом верхнем углу.
3. Выберите «Export chat history» (Экспорт истории чата).
4. Укажите параметры:
   *   **Период** (или выберите «Вся история»).
   *   **Формат**: HTML (читаемый) или JSON (машиночитаемый).
   *   **Размер медиафайлов**: до 8 МБ на файл, до 4 ГБ на весь архив.
5. Нажмите «Export» и дождитесь завершения.

### Что входит в архив

*   Тексты сообщений, включая пересланные.
*   Фотографии, видео, GIF-анимации.
*   Стикеры, файлы, документы.
*   Голосовые и видеосообщения.
*   Метаданные: даты, ID отправителей, счётчики просмотров.

## Способ 2: Утилита командной строки tgarc

[tgarc](https://github.com/ruarxive/tgarc) — наш собственный инструмент
для архивирования контента из Telegram в машиночитаемом JSON-формате.

Преимущества перед ручным экспортом:

*   **Пакетная выгрузка** — можно задать список каналов и выгрузить
  их одной командой.
*   **Регулярные обновления** — легко встроить в cron/systemd timer.
*   **Машиночитаемый JSON** с предсказуемой структурой.
*   **Сохранение служебных полей**, которые Telegram Desktop
  «теряет» при экспорте в HTML.

### Установка

```bash
pip install tgarc
```

### Пример использования

```bash
tgarc export --channel @channel_name --output ./archive/
```

## Способ 3: Telegram API + собственный скрипт

Если нужна интеграция в исследовательский пайплайн, можно использовать
[Telethon](https://docs.telethon.dev/) или [Pyrogram](https://docs.pyrogram.org/)
для прямого доступа к Telegram MTProto API. Этот способ требует
регистрации собственного `api_id` / `api_hash` и аккуратного соблюдения
лимитов Telegram (не более 200 запросов в минуту на одну сессию).

## Ограничения

*   **Лимиты на медиа**: до 4 ГБ на один экспорт (увеличивается
  платно через Telegram Premium).
*   **Удалённые сообщения** в архив не попадают.
*   **Секретные чаты** не поддерживают экспорт.
*   **Голосовые сообщения в высоком качестве** сохраняются в обычном OGG.

## Что делать с большими каналами

Для каналов с миллионами сообщений и сотнями гигабайт медиа рекомендуется
**комбинировать подходы**:

1. Сначала [tgarc](https://github.com/ruarxive/tgarc) для текстовой истории.
2. Затем [yt-dlp](https://github.com/yt-dlp/yt-dlp) для выгрузки
   конкретных видео по списку URL.
3. [metawarc](/kb/instruments/ruarxive-tools/metawarc) для индексации
   и поиска по итоговой коллекции.
