# Как выгрузить свой аккаунт Mastodon

В настройках Mastodon две разные выгрузки. Их часто путают, потому что они лежат на одной странице. Описание ниже следует [документации Mastodon](https://docs.joinmastodon.org/user/moving/) (раздел об экспорте при переезде). Подписи в интерфейсе зависят от сервера и языка.

Откройте **Settings → Import and export → Export** (в части интерфейсов это Preferences).

## Списки CSV

Сразу скачиваются файлы текущих подписок, списков, блокировок аккаунтов, мьютов и блокировок доменов, а также закладок. Эти CSV импортируются на другом сервере: **Import and export → Import**, режимы Merge или Overwrite. Для переезда аккаунта нужны они, а не архив постов.

## Архив постов и медиа

Кнопка запроса архива готовит посты и загруженные файлы в JSON формата Activity Streams 2.0. Запрашивать архив можно раз в семь дней. Импортировать посты и медиа обратно в Mastodon нельзя: документация прямо говорит о техническом ограничении. Архив нужен как ваша копия. Его читает программа, которая понимает Activity Streams.

Архив не заменяет CSV и не переносит подписки.

## Чужие публичные посты

Лента и профиль, открытые без входа, читаются публичным API сервера. Это уже не выгрузка своего аккаунта: см. [Mastodon, Bluesky, Threads](/kb/instruments/social-media/mastodon). Полный обход чужого инстанса через API там же назван непрактичным из-за лимитов.
