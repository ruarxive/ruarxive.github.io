# Yandex Data Takeout

Яндекс предоставляет возможность выгрузки данных через сервис
управления аккаунтом (Yandex ID). В отличие от Google Takeout, здесь
нет единого «центра выгрузки» для всего сразу, но есть инструменты
для ключевых сервисов.

Адрес управления данными: [passport.yandex.ru/profile/data](https://passport.yandex.ru/profile/data)

## Яндекс.Диск

Для полного скачивания Яндекс.Диска проще всего использовать:

1.  **Клиент Яндекс.Диска для ПК** — синхронизировать всё на локальный
  диск. Подходит для Windows, macOS, Linux.
2.  **WebDAV** — подключить диск как сетевой и скопировать файлы:

    ```bash
    # Подключение через davfs2
    mount -t davfs https://webdav.yandex.ru /mnt/yandex

    # Или через cadaver
    cadaver https://webdav.yandex.ru
    ```

3.  **rclone** — для регулярных бэкапов в другое облако или на локальный
  диск:

    ```bash
    rclone config  # добавить yandex-disk remote
    rclone sync yandex-disk:/ /backup/yandex/
    ```

## Яндекс.Почта

Официального экспорта в MBOX нет. Рекомендуется использовать почтовый
клиент (Thunderbird, Outlook, Claws Mail) по протоколу **IMAP** для
выкачивания всех писем на локальный компьютер:

*   Включите IMAP в настройках Яндекс.Почты.
*   Настройте клиент на `imap.yandex.ru:993` (SSL).
*   Скопируйте нужные папки локально.
*   Экспортируйте в MBOX через Thunderbird.

## Другие сервисы

На странице «Управление данными» можно запросить архив с информацией
из сервисов:

*   Музыка
*   Карты
*   Кинопоиск
*   Маркет
*   Дзен
*   Алиса (голосовые запросы)
*   Такси
*   Устройства

Запрос архива может занять **от нескольких часов до 7 дней**. Вы
получите уведомление на почту. Данные обычно приходят в формате
**JSON** или **CSV**.

## Яндекс.Метрика

Если у вас есть счётчик Метрики, данные о посетителях **не входят в
Data Takeout** — это сервисная аналитика. Однако вы можете:

*   Скачать **CSV-выгрузки** из отчётов Метрики (до 1 года данных).
*   Использовать **API Метрики** для программного доступа.
*   Включить **экспорт в Google BigQuery** для долгосрочного хранения.

## Ограничения

*   **Яндекс.Почта для доменов** требует обращения к администратору
  домена — обычный Data Takeout не работает.
*   **Яндекс.Деньги (ЮMoney)** имеет отдельный интерфейс выгрузки
  истории операций.
*   **Связанные аккаунты** (OAuth-авторизации) нужно отзывать
  отдельно.

## Что делать, если доступ к аккаунту утрачен

1. Восстановите доступ через [passport.yandex.ru](https://passport.yandex.ru/).
2. Если не получается — обратитесь в поддержку с подтверждением
   личности.
3. Для доменной почты — обратитесь к администратору домена.
