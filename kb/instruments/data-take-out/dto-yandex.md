# Yandex Data Takeout

У Яндекса есть единый центр выгрузки персональных данных — раздел «Данные на сервисах» в Яндекс ID: [id.yandex.ru/personal/data](https://id.yandex.ru/personal/data). Но содержимое Яндекс Диска и письма Яндекс Почты удобнее сохранять отдельно — способы описаны ниже.

## Архив данных через Яндекс ID

По [справке Яндекс ID](https://yandex.ru/support/id/ru/data):

1. Откройте «Управление данными» → «Данные на сервисах» и убедитесь, что вошли с нужным Яндекс ID.
2. Выберите сервис и нажмите «Заказать архив с данными».
3. Следите за статусом на странице управления данными. Готовый архив появится в разделе «Список заказанных архивов» — там же будет пароль для распаковки.

Особенности:

*   обычно архив формируется в пределах суток, но может занять **до 30 дней**;
*   данные каждого сервиса лежат в отдельной папке, форматы — **XML, JSON и CSV**;
*   на macOS для распаковки нужен архиватор с поддержкой формата 7-Zip;
*   некоторые сервисы хранят не все данные или хранят их ограниченное время, поэтому в архиве может быть не всё, что вы ожидаете.

## Яндекс Диск

Для полного скачивания Яндекс Диска:

1.  **Приложение Яндекс Диска для компьютера** — синхронизирует файлы на локальный диск.
2.  **[rclone](https://rclone.org/yandex/)** — для регулярного копирования на локальный диск или в другое хранилище. Подключение настраивается командой `rclone config` (тип хранилища `yandex`), затем:

    ```bash
    rclone sync yandex-disk:/ /backup/yandex/
    ```

3.  **[ydiskarc](/kb/instruments/ruarxive-tools/ydiskarc)** — утилита Ruarxive для архивации **публичных** папок Яндекс Диска по ссылке.

## Яндекс Почта

Официального экспорта в MBOX нет. Сохраните письма через почтовую программу по протоколу IMAP ([справка Яндекс Почты](https://yandex.ru/support/yandex-360/customers/mail/ru/mail-clients/others)):

1.  В настройках Яндекс Почты, в разделе «Почтовые программы», включите доступ по IMAP и опцию «Пароли приложений и OAuth-токены».
2.  Создайте пароль приложения для почты в Яндекс ID.
3.  Настройте программу (например, Thunderbird): сервер `imap.yandex.ru`, порт `993`, SSL; логин и пароль приложения.
4.  Дождитесь синхронизации папок и экспортируйте их в MBOX средствами программы.

## Яндекс Метрика

Данные о посетителях сайтов из Метрики — это данные вашего счётчика, а не персональные данные аккаунта. Сохранять их можно так:

*   выгружать отчёты из интерфейса Метрики;
*   получать данные программно через API Метрики, в том числе сырые данные о визитах и просмотрах через Logs API.

## Ограничения

*   **Почта для домена** (Яндекс 360 для бизнеса) — выгрузку настраивает администратор организации.
*   **Сервисы, которые больше не входят в Яндекс** (например, Дзен и ЮMoney), выгружают данные через собственные интерфейсы.
*   **Сторонние сайты с входом через Яндекс ID** хранят свои данные сами.

## Если доступ к аккаунту утрачен

1. Восстановите доступ через страницу входа Яндекс ID.
2. Если не получается — обратитесь в поддержку.
3. Для почты домена — обратитесь к администратору организации.
