# Instagram

Архивация Instagram сложна из-за агрессивных анти-бот мер платформы.

## Instaloader

[Instaloader](https://instaloader.github.io/) — мощный инструмент командной строки на Python для скачивания фотографий, видео и метаданных из Instagram.

### Установка

```bash
pip install instaloader
```

### Использование

```bash
instaloader profile_name
```

### Важные советы

1.  **Логин**: Для скачивания большинства контента требуется вход в аккаунт (`--login`).
2.  **Лимиты**: Instagram быстро банит за слишком частые запросы. Не запускайте массовую архивацию с основного аккаунта.
3.  **Сессии**: Сохраняйте файл сессии, чтобы не логиниться каждый раз (это подозрительно для Instagram).

## Другие методы

Для создания достоверной копии внешнего вида страниц (включая комментарии) лучше использовать [Browsertrix](../tools/browsertrix) в режиме записи с профилем браузера.

## Массовая архивация Instagram аккаунтов в РФ

В рамках кампании по сохранению официальных аккаунтов российских политиков
Ruarxive в 2022 году был выполнен сбор 171 аккаунта с использованием `instaloader`
([Публикация #28 в канале Ruarxive](https://t.me/ruarxive/28)). В результате:

- Получено около 1,4 ГБ архивных данных.
- Собраны сообщения, метаданные, изображения.
- Код выложен в открытый репозиторий `ruarxive/rugovinstagrams`.

> [!WARNING]
> **Лимиты API Instagram** для российских IP жёстче, чем в среднем по миру. Кроме того,
> в 2024 году Instagram в РФ официально заблокирован; доступ возможен только через
> VPN/Tor. Планируйте архивацию с учётом этих ограничений.
