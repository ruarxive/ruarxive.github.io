# ВКонтакте

Архивация ВКонтакте возможна через официальный VK API и сторонние инструменты. VK API открыт для разработчиков: документация и регистрация приложений — на [dev.vk.com](https://dev.vk.com/).

## Официальный API

### Получение ключа доступа

Методы VK API вызываются с ключом доступа (`access_token`). В описании каждого метода указано, какие типы ключей он принимает: ключ пользователя, ключ сообщества или сервисный ключ. Например, [`wall.get`](https://dev.vk.com/ru/method/wall.get) (записи со стены) работает с ключом пользователя и с сервисным ключом.

1. Создайте приложение на [dev.vk.com](https://dev.vk.com/).
2. Для чтения публичных стен достаточно **сервисного ключа** из настроек приложения.
3. Для данных, доступных только участникам (закрытые сообщества), нужен ключ пользователя, у которого есть к ним доступ.

### Скрипт для архивации стены сообщества

```python
import json
import time

import requests

TOKEN = "ваш_сервисный_ключ"
OWNER_ID = -123456  # отрицательное число — сообщество
API_VERSION = "5.131"


def fetch_posts(owner_id, offset=0):
    response = requests.get(
        "https://api.vk.ru/method/wall.get",
        params={"owner_id": owner_id, "offset": offset, "count": 100, "v": API_VERSION},
        headers={"Authorization": f"Bearer {TOKEN}"},
        timeout=30,
    )
    data = response.json()
    if "error" in data:
        raise RuntimeError(data["error"])
    return data["response"]


all_posts = []
offset = 0
while True:
    items = fetch_posts(OWNER_ID, offset)["items"]
    if not items:
        break
    all_posts.extend(items)
    offset += 100
    time.sleep(0.5)  # соблюдаем лимиты API

with open("vk_archive.json", "w", encoding="utf-8") as f:
    json.dump(all_posts, f, ensure_ascii=False, indent=2)
```

Скрипт сохраняет записи в JSON, но не скачивает вложения: фотографии и видео нужно загружать отдельно по ссылкам из ответа или инструментами ниже.

## Ограничения API

- **Частота запросов** ([документация](https://dev.vk.com/ru/api/api-requests)): ключ пользователя — 3 запроса в секунду, ключ сообщества — 20, сервисный ключ — от 5 до 60 запросов в секунду в зависимости от числа пользователей приложения. При превышении API возвращает ошибку 6 «Too many requests per second».
- **Количественные лимиты** на однотипные методы VK не раскрывает; при их превышении метод может временно стать недоступен или потребовать капчу.
- **`wall.get`** отдаёт не более 100 записей за запрос.
- **Закрытые сообщества** — только с ключом участника.
- **Собственная переписка** — сохраняйте через официальную выгрузку данных, см. [Как сохранить данные из ВКонтакте](/kb/instruments/data-take-out/dto-vk).

## Другие инструменты

- **[yt-dlp](/kb/instruments/tools/yt-dlp)** — видео из VK Видео.
- **[gallery-dl](/kb/instruments/tools/gallery-dl)** — фотоальбомы, фотографии пользователя и отдельные записи со стены.
- **[Browsertrix](/kb/instruments/tools/browsertrix)** — визуальная копия страниц в WARC/WACZ, если нужен внешний вид, а не только данные.

Сохранение HTML-страниц через Wget — крайняя мера: разметка VK генерируется скриптами, и результат часто неполон.

## Инструменты Ruarxive

Для VK пока нет готового инструмента от Ruarxive (как `wparc` для WordPress). Это одна из задач для волонтёров — см. [Задачи для волонтёров-разработчиков](/kb/volunteers/volunteers-tasks).

## Персональные данные

При архивации ВКонтакте помните о [персональных данных](/kb/legal/personal-data). Публичная доступность страницы не означает согласия на распространение данных: сохранение и публикация постов конкретных людей требует их согласия либо иного правового основания.
