# Rutube

Rutube — крупнейшая российская видеоплатформа после YouTube. Архивируется средствами
`yt-dlp`, который поддерживает Rutube «из коробки».

## Базовое скачивание

```bash
yt-dlp --write-description \
       --write-info-json \
       --write-thumbnail \
       --embed-metadata \
       "https://rutube.ru/video/UUID/"
```

## Скачивание канала целиком

```bash
yt-dlp --download-archive rutube-archive.txt \
       -o "%(uploader)s/%(title)s.%(ext)s" \
       "https://rutube.ru/u/USERNAME/"
```

Опция `--download-archive` запоминает скачанные ID и пропускает их при повторных запусках.

## Субтитры и метаданные

Rutube обычно имеет субтитры для большинства видео:

```bash
yt-dlp --write-subs --sub-langs ru,en --embed-subs \
       "https://rutube.ru/video/UUID/"
```

Полные метаданные сохраняются в `*.info.json` рядом с видеофайлом.

## Ограничения

- **Возрастные ограничения** — некоторые видео требуют авторизации.
- **Платный контент** — недоступен без подписки.
- **Геоблокировки** — могут срабатывать за пределами РФ (и наоборот).
- **Лимиты скорости** — агрессивный обход вызывает временный бан.

## Архивирование комментариев

`yt-dlp` поддерживает `--write-comments` для некоторых сайтов, но для Rutube эта опция
не всегда работает стабильно.

Альтернативный путь — собирать комментарии через API Rutube
(требует токен приложения) или через HTML-парсинг с Browsertrix.

## Практика Ruarxive

Rutube активно архивировался в 2022 году как часть проекта «Российские СМИ». См.
