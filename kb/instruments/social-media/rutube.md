# Rutube

Rutube — российская видеоплатформа. Видео и каналы архивируются с помощью [yt-dlp](/kb/instruments/tools/yt-dlp), в котором есть встроенная поддержка Rutube.

## Базовое скачивание

```bash
yt-dlp --write-description \
       --write-info-json \
       --write-thumbnail \
       --embed-metadata \
       "https://rutube.ru/video/VIDEO_ID/"
```

## Скачивание канала целиком

yt-dlp распознаёт адреса каналов вида `rutube.ru/channel/<число>/` (а также старый формат `rutube.ru/u/<имя>/`) и плейлисты `rutube.ru/plst/<число>/`.

```bash
yt-dlp --download-archive rutube-archive.txt \
       -o "%(uploader)s/%(title)s [%(id)s].%(ext)s" \
       "https://rutube.ru/channel/CHANNEL_ID/videos/"
```

Опция `--download-archive` запоминает скачанные ID и пропускает их при повторных запусках.

## Субтитры и метаданные

Если у видео есть субтитры, их можно сохранить отдельно или встроить в файл:

```bash
yt-dlp --write-subs --sub-langs ru --embed-subs \
       "https://rutube.ru/video/VIDEO_ID/"
```

Полные метаданные сохраняются в `*.info.json` рядом с видеофайлом.

> Адреса и флаги сверены с yt-dlp 2026.08.19 (октябрь 2026).

## Ограничения

- **Возрастные ограничения** — некоторые видео требуют авторизации (используйте `--cookies-from-browser`).
- **Платный контент** — недоступен без подписки.
- **Географические ограничения** — некоторые видео могут быть недоступны за пределами России.
- **Частота запросов** — слишком интенсивное скачивание приводит к временной блокировке.

## Комментарии

Экстрактор Rutube в yt-dlp комментарии не извлекает: опция `--write-comments` для Rutube не сработает. Для сохранения страниц вместе с комментариями используйте браузерную архивацию через [Browsertrix](/kb/instruments/tools/browsertrix).

Плейлисты и каналы имеют отдельные шаблоны адресов (`/plst/`, `/channel/`, старый `/u/`). Если yt-dlp пишет, что адрес не поддержан, сверьте его с `--list-extractors` установленной версии, а не со старым примером. Общий разбор флагов — на странице [yt-dlp](/kb/instruments/tools/yt-dlp). Видео ВКонтакте и YouTube туда же; у ВКонтакте есть ещё и API стены, это другой тип архива: [ВКонтакте](/kb/instruments/social-media/vk).

## Rutube в практике Ruarxive

В публикациях Ruarxive о поиске записей предвыборных теледебатов ([#122](https://t.me/ruarxive/122), март 2024; [#191](https://t.me/ruarxive/191), август 2026) Rutube упоминается среди площадок, где федеральные телеканалы не выложили записи эфиров. Подробнее о сохранении материалов СМИ — в разделе [Архивы контента российских СМИ](/kb/projects/russian-smi).
