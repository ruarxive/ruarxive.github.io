# Площадки, у которых API уже нет

Инструкция пятилетней давности часто ведёт на кнопку, которой больше нет. Ниже — замены, уже описанные в этой базе. Дата закрытия указана только там, где она есть на соответствующей странице.

| Было | Что случилось | Чем пользоваться теперь |
|---|---|---|
| Twitter Academic Research API | Закрыт в 2023 году | Платный API v2 и выгрузка своего архива: [twarc](/kb/instruments/social-media/twarc), [экспорт X](/kb/instruments/data-take-out/dto-twitter) |
| Twitter API v1.1 в старых скриптах | Бесплатный широкий доступ снят | То же. Снимки уже исчезнувших страниц — Wayback Machine и [archive.ph](/kb/instruments/tools/archive-ph) |
| CrowdTangle | Закрыт в августе 2024 года | Для исследователей Meta — Meta Content Library, см. [Facebook](/kb/instruments/social-media/facebook) |
| Instagram Basic Display API | Отключён 4 декабря 2024 года | Выгрузка своего аккаунта, Instaloader и браузерный снимок: [Instagram](/kb/instruments/social-media/instagram) |
| Conifer (Rhizome) | С июня 2026 года новые захваты не принимаются, старые коллекции открыты для просмотра | [Browsertrix](/kb/instruments/tools/browsertrix) и расширение ArchiveWeb.page |
| Social Feed Manager | GWU прекратил разработку в 2024 году и закрыл свой хостинг | Страница оставлена как справка: [Social Feed Manager](/kb/instruments/social-media/social-feed-manager) |
| F(b)arc | Репозиторий в архиве с 2018 года | [Facebook](/kb/instruments/social-media/facebook) |
| tgarc на Pyrogram | Репозиторий не менялся с 15 декабря 2023 года, Pyrogram архивирован | [tdl](/kb/instruments/tools/tdl) и [экспорт Telegram](/kb/instruments/data-take-out/dto-telegram) |
| OpenWayback | Не развивается, для новых установок не рекомендуется | [pywb](/kb/instruments/replay/pywb) |
| Crocoite | Репозиторий архивирован владельцем 25 апреля 2021 года, последний push — декабрь 2019 | [Browsertrix](/kb/instruments/tools/browsertrix) |

Срез «что ещё живое» — на странице [ландшафта 2026](/kb/instruments/landscape-2026) и в [списке новых и уходящих инструментов](/kb/resources/curated-lists).

## Как не скопировать устаревший рецепт

- Смотрите `last_update` в шапке страницы и блок «когда не использовать».
- Если команда требует ключ Academic API, CrowdTangle или регистрацию в Conifer, она описывает прошлый сервис.
- Официальная выгрузка своего аккаунта переживает закрытие API для чужих данных чаще, чем сторонний краулер. Начните с [Data Take-Out](/kb/instruments/data-take-out/data-take-out-main).
