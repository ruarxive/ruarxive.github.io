# Hitomi Downloader

[Hitomi Downloader](https://github.com/KurtBestor/Hitomi-Downloader) — программа для Windows с GUI поверх yt-dlp / собственных экстракторов. Поддерживает **большое разнообразие сайтов**, включая:

- YouTube, Vimeo, TikTok (через yt-dlp);
- специализированные источники: pixiv, Mangadex, fandom-галереи;
- собственные экстракторы для крупных изображений и галерей;
- HLS-стримы (через ffmpeg).

## Когда использовать

✅ Подходит, если:

- работаете в Windows и хотите GUI с широкими возможностями;
- нужна поддержка сайтов, **не представленных в yt-dlp** или с ограниченной поддержкой;
- нужно делать **пакетные загрузки** (список URL → очередь).

❌ Не подходит:

- для Linux/macOS — нет стабильного порта, используйте CLI-альтернативы;
- если нужно профессиональное качество и контейнер MKV/MP4 — настройки yt-dlp будут точнее.

## Особенности

- **Мульти-потоковая загрузка** HLS: сборка .ts → ffmpeg-мерж.
- **Drag&drop URL** из браузера.
- **Расписание и пакеты**: можно класть большой список URL и уйти.
- **Поддержка тегов/метаданных** для последующего архивирования.

## Практическая работа с коллекциями

```text
1. Соберите список URL в один файл URL.txt
2. Откройте в Hitomi → File → Open URL list
3. Запустите очередь
4. После завершения — проверьте целостность файлов (CRC/MD5)
```
