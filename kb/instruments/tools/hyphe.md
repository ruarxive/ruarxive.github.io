# Hyphe

[Hyphe](https://github.com/medialab/hyphe) — исследовательский веб-краулер с веб-интерфейсом, разработанный в [médialab Sciences Po](https://medialab.sciencespo.fr/). Он помогает собрать **веб-корпус**: обойти стартовые сайты, найти сайты, на которые они ссылаются, решить, какие из них включать в исследование, и получить граф связей между ними. Лицензия — AGPL-3.0.

Ключевое понятие Hyphe — **веб-сущность** (web entity). Это единица анализа, которую задаёт исследователь: отдельная страница, сайт, поддомен, раздел сайта или их комбинация.

## Когда использовать

✅ Подходит, если:

- нужно **собрать тематический корпус** сайтов (например, региональные СМИ или университетские сайты) и обосновать его границы;
- нужно **решить, какие домены включать**, а какие — нет, опираясь на реальные ссылки между сайтами;
- нужен **граф ссылок** между сайтами для анализа в [Gephi](https://gephi.org/).

❌ Не подходит:

- если нужно просто скачать сайт для архива — это работа для [wget](/kb/instruments/tools/wget), [wpull](/kb/instruments/tools/wpull) или [Browsertrix Crawler](/kb/instruments/tools/browsertrix); Hyphe не создаёт WARC;
- если сайтов очень много (сотни тысяч и больше) — Hyphe рассчитан на интерактивную ручную работу исследователя.

## Основные понятия

- **Корпус** — проект в Hyphe: набор веб-сущностей, обходов и ссылок.
- **Веб-сущность** — страница, сайт, поддомен или их комбинация. Например, исследователь сам решает, считать ли `kremlin.ru` и `en.kremlin.ru` одной сущностью или двумя.
- **Статус веб-сущности**: `IN` (входит в корпус), `OUT` (исключена), `UNDECIDED` (решение не принято), `DISCOVERED` (найдена по ссылкам, ещё не рассмотрена).
- **Ссылки** — гиперссылки между веб-сущностями, из которых строится граф.

## Установка

Рекомендуемый способ — Docker (по README проекта):

```bash
git clone https://github.com/medialab/hyphe.git hyphe
cd hyphe
cp .env.example .env
cp config-backend.env.example config-backend.env
cp config-frontend.env.example config-frontend.env
docker compose pull
docker compose up -d
```

Когда в логах появится «All tests passed. Ready!», интерфейс будет доступен по адресу `http://localhost:80/` (порт задаётся переменной `PUBLIC_PORT` в `.env`). Hyphe активно расходует диск: по README большой корпус может занять до 50 ГБ.

Внутри работают бэкенд на Python (Twisted), краулер на Scrapy и база MongoDB.

> Команды сверены с README репозитория `medialab/hyphe` (последний релиз v1.12.2, октябрь 2026).

## Использование

1. Создайте корпус в веб-интерфейсе.
2. Добавьте стартовые URL — Hyphe создаст для них веб-сущности.
3. Запустите обход выбранных сущностей с нужной глубиной.
4. Просмотрите найденные сущности со статусом `DISCOVERED` и присвойте им `IN`, `OUT` или `UNDECIDED`; при необходимости объедините или разделите сущности.
5. Повторяйте обход для новых сущностей со статусом `IN`, пока корпус не стабилизируется.

### Экспорт

Списки веб-сущностей можно выгрузить в CSV, а граф ссылок — в формате GEXF для [Gephi](https://gephi.org/). Список URL сущностей со статусом `IN` затем можно передать в [Browsertrix Crawler](/kb/instruments/tools/browsertrix) или [wget](/kb/instruments/tools/wget) для архивации.
