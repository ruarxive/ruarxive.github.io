# GUI-обёртки для yt-dlp и youtube-dl

[yt-dlp](https://github.com/yt-dlp/yt-dlp) — это форк youtube-dl с активной поддержкой и расширенным набором сайтов. Это консольный инструмент. Для пользователей, не работающих в командной строке, существуют GUI-обёртки, которые дают:

- визуальный интерфейс (вставка ссылки → загрузка);
- очередь загрузок с прогрессом;
- выбор качества, формата, субтитров;
- интеграция с системным браузером (перехват кликов).

## Когда использовать

✅ Подходит, если:

- работаете с волонтёрами, не знакомыми с командной строкой;
- нужен быстрый способ собирать медиа с YouTube и других платформ;
- нужна пакетная работа (список ссылок → загрузка по расписанию).

❌ Не подходит:

- для скриптов/конвейеров — используйте [yt-dlp](/kb/instruments/tools/yt-dlp) напрямую;
- если нужна детальная настройка форматов (GUI часто ограничены).

## Сравнение GUI-обёрток

| Программа | Платформа | Сайтов | Особенности |
|---|---|---|---|
| **[dvd](https://github.com/dsheeler525/dvd)** (David Video Downloader) | macOS | 100+ | GUI поверх yt-dlp, drag&drop, очередь |
| **[Hitomi Downloader](https://github.com/KurtBestor/Hitomi-Downloader)** | Windows | много | Поддерживает специализированные сайты (Manga, pixiv). |
| **[FireDM](https://github.com/firedm/FireDM)** | Windows/Linux/macOS | 100+ | Python+PyQt, открытый исходник. |
| **[youtube-dl-gui](https://github.com/StefanLobbenmeier/youtube-dl-gui)** | кросс-платформенный | 100+ | Electron-обёртка youtube-dl (старее, не yt-dlp). |

## DVD — David Video Downloader

```bash
# На macOS через Homebrew
brew install david-video-downloader
```

**Особенности:**

- drag&drop ссылок прямо из браузера;
- встроенный просмотр очереди;
- поддержка субтитров, метаданных, выбора качества.

## Hitomi Downloader

- Поддерживает популярные «сложные» сайты: pixiv, специализированные видеохостинги.
- Мульти-потоковая загрузка.
- Удобен для сегментированных файлов.

## FireDM

- Открытый исходный код.
- Лёгкий Python+PyQt.
- Поддерживает докачку, расписание.

## Практические советы

1. **Доверие к источникам:** берите GUI-обёртки только из проверенных репозиториев (GitHub с высокой звёздностью); «дистрибутивы» из непроверенных сайтов — частая ловушка для malware.
2. **Соблюдение ToS платформ:** даже с GUI вы должны понимать, что скачивание контента с YouTube ограничено правилами.
3. **Формат вывода:** при сохранении в MKV/MP4 обращайте внимание на кодеки и контейнер — для архивации предпочтительны «без потерь» или максимально совместимые параметры.
