# Archive.ph: полное руководство

**Archive.ph** (также известный как Archive.today, Archive.is) - это бесплатный сервис для моментального создания постоянных снимков веб-страниц. Один из самых простых и быстрых инструментов для архивации.

## Что такое Archive.ph

Archive.ph создает **неизменяемый снимок** веб-страницы в том виде, в каком она существует прямо сейчас. После создания архив:
- ✅ Хранится бессрочно
- ✅ Не может быть изменен или удален
- ✅ Доступен по уникальной постоянной ссылке
- ✅ Не требует регистрации

### Зеркала сервиса

Archive.ph имеет несколько доменных имен (все ведут на один сервис):
- archive.ph (текущий основной)
- archive.today
- archive.is
- archive.fo
- archive.li

Если один домен недоступен, попробуйте другой.

---

## Когда использовать Archive.ph

### ✅ Идеально подходит для:

- **Срочной архивации:** Результат через 10-30 секунд
- **Отдельных страниц:** Новости, статьи, посты в соцсетях
- **Доказательства существования:** Временная метка + постоянная ссылка
- **Обход блокировок:** Сохранение контента, который может исчезнуть
- **Простоты:** Не требует технических навыков

### ⚠️ Не подходит для:

- Страниц с авторизацией (сохраняет только публичную версию)
- Сложных интерактивных приложений (сохраняет статичный снимок)
- Целых сайтов (архивируется только одна страница за раз)
- Видео и аудио плееров (может не сохранить медиа корректно)

## Как использовать веб-интерфейс

### Базовая архивация (30 секунд)

1. Откройте [archive.ph](https://archive.ph)
2. Введите URL страницы в поле **"My url is alive and I want to archive its content"**
3. Нажмите красную кнопку **"Save"**
4. Подождите 10-30 секунд
5. **Сохраните полученную ссылку!**

**Пример результата:**  
`https://archive.ph/AbCdE` - это постоянная ссылка на ваш архив

### Поиск существующих архивов

Перед созданием нового архива проверьте, нет ли уже сохраненных:

1. На главной странице archive.ph найдите поле **"I want to search the archive"**
2. Введите URL или ключевые слова
3. Нажмите **"Search"**
4. Просмотрите список архивов с датами создания

**Полезно:** Можно увидеть историю изменений страницы

## Продвинутое использование

### Архивация через GET-запрос

Можно создать архив, просто открыв специальный URL:

```
https://archive.ph/?run=1&url=https://example.com
```

Замените `https://example.com` на нужный вам URL.

**Применение:** Добавьте этот URL в закладки с переменной для быстрой архивации.

### Массовая архивация (с осторожностью!)

Archive.ph **не предоставляет официального API**, но можно использовать GET-запросы.

**⚠️ Важно:**
- Не делайте больше 1 запроса в секунду
- Не архивируйте тысячи страниц подряд
- Сервис может временно заблокировать ваш IP

**Пример скрипта (Python):**

```python
import requests
import time

urls = [
    "https://example.com/page1",
    "https://example.com/page2",
    # ...
]

for url in urls:
    archive_url = f"https://archive.ph/?run=1&url={url}"
    response = requests.get(archive_url, allow_redirects=True)
    
    # Итоговый URL - это адрес архива
    print(f"Archived: {response.url}")
    
    # Задержка 3 секунды между запросами
    time.sleep(3)
```

**Альтернатива:** Для массовой архивации лучше использовать [Internet Archive API](https://archive.org/help/wayback_api.php)

## Archive.ph vs Wayback Machine

| Критерий | Archive.ph | Internet Archive (Wayback Machine) |
|----------|------------|-----------------------------------|
| **Скорость** | ⚡ Очень быстро (10-30 сек) | 🐢 Медленнее (1-5 минут) |
| **Регистрация** | ❌ Не требуется | ❌ Не требуется для просмотра, ✅ нужна для сохранения |
| **API** | ⚠️ Неофициальный | ✅ Официальный |
| **Надежность хранения** | ⚠️ Один сервис (риск закрытия) | ✅ Некоммерческая организация, 25+ лет |
| **Доступность в РФ** | ✅ Обычно доступен | ⚠️ Периодически блокируется |
| **Приватность** | ✅ Не требует данных | ⚠️ Может требовать регистрацию |
| **Поиск** | ⚠️ Базовый | ✅ Продвинутый |
| **Массовая архивация** | ❌ Не предусмотрена | ✅ Поддерживается через API |

### Рекомендации

**Используйте Archive.ph когда:**
- Нужна максимальная скорость
- Архивируете 1-10 страниц
- Важна простота
- Wayback Machine недоступен

**Используйте Wayback Machine когда:**
- Архивация для долгосрочного хранения
- Нужна массовая архивация
- Требуется API
- Делаете исследовательский проект

**🔥 Лучшая практика:** Архивируйте важный контент в **оба сервиса** для надежности!

## Особенности и ограничения

### ✅ Что сохраняется хорошо

- Текстовый контент (статьи, новости)
- Статичные изображения
- Базовый HTML и CSS
- Встроенные стили страницы
- Мета-информация (title, description)

### ⚠️ Что может не сохраниться

- **JavaScript-контент:** Динамически загружаемые элементы (комментарии, бесконечная прокрутка)
- **Видео/аудио плееры:** Могут сохраниться как статичные блоки
- **Iframe-контент:** Встроенные элементы с других доменов
- **Контент за авторизацией:** Личные кабинеты, закрытые группы
- **Динамические формы:** Интерактивные элементы

### Временные метки

Каждый архив содержит точное время создания:
- Формат: UTC (всемирное координи��ованное время)
- Отображается вверху архивной страницы
- **Юридическая значимость:** Может служить доказательством существования контента в определенный момент

## Приватность и безопасность

### Что нужно знать

**Archive.ph НЕ является анонимным:**
- Ваш IP-адрес виден сервису при создании архива
- Созданные архивы **публичны** и доступны всем
- Невозможно удалить созданный архив

**Рекомендации:**
- Используйте VPN if you want privacy
- Не архивируйте страницы с вашими личными данными
- Помните: один раз заархивировано = навсегда в интернете

### Удаление архивов

**Archive.ph НЕ предоставляет функции удаления архивов.**

Если вы случайно заархивировали что-то:
1. Свяжитесь с администрацией через форму на сайте
2. Объясните ситуацию (только серьезные причины: личные данные, безопасность)
3. Ждите ответа (может занять дни/недели, успех не гарантирован)

**Важно:** Планируйте перед архивацией, проверяйте URL!

## Практические примеры использования

### Пример 1: Архивация новостной статьи

**Ситуация:** Важная статья может быть отредактирована или удалена

```
1. Копируем URL: https://news-site.com/article/123
2. Идем на archive.ph
3. Вставляем URL → Save
4. Получаем: https://archive.ph/Xy9Zq
5. Сохраняем ссылку в заметки/документ
```

**Результат:** Постоянное доказательство оригинального текста

---

### Пример 2: Архивация поста в Twitter/X

**Ситуация:** Скандальный твит, который могут удалить

```
1. Открываем конкретный твит
2. Копируем URL (должен содержать /status/...)
3. Архивируем через archive.ph
4. Сохраняем и делимся архивной ссылкой
```

**Совет:** Архивируйте быстро! Твиты могут удаляться за минуты.

---

### Пример 3: Сохранение доказательной базы

**Ситуация:** Сбор доказательств нарушений, фальсификаций

1. Найдите материал (пост, статья, страница)
2. Заархивируйте через archive.ph
3. Скриншот архивной страницы (дополнительная страховка)
4. Сохраните ссылку + скриншот + дату

**Зачем:** Timestamp от Archive.ph может использоваться как свидетельство

## Альтернативы Archive.ph

Если Archive.ph не работает или не подходит:

### [Perma.cc](https://perma.cc)
- Для академических и юридических целей
- Требует регистрацию через университет/организацию
- Более официальный статус

### [Conifer](https://conifer.rhizome.org)
- Для интерактивных страниц с JavaScript
- Записывает браузерную сессию
- Требует регистрацию

### [Wayback Machine](https://web.archive.org)
- Самый надежный для долгосрочного хранения
- Огромная история архивов
- Может быть медленнее

### Локальные инструменты
- **SingleFile** (расширение браузера) - сохранение в HTML
- **WebScrapBook** (Firefox/Chrome) - организованная коллекция
- **HTTrack** - для офлайн-копий сайтов

## Частые вопросы (FAQ)

**Q: Можно ли архивировать страницы Instagram/Facebook?**  
A: Да, но только публичный контент. Страницы за авторизацией не сохранятся.

**Q: Куда сохраняются медиафайлы (фото, видео)?**  
A: Фото обычно сохраняются, видео могут не проиграть (сохраняется только превью).

**Q: Можно ли обновить архив?**  
A: Нет, каждый архив неизменяем. Создайте новый архив с той же ссылкой.

**Q: Archive.ph заблокирован, что делать?**  
A: Попробуйте зеркала (archive.today, archive.is) или используйте VPN.

**Q: Сколько архивов можно создать?**  
A: Нет официального лимита, но не злоупотребляйте (риск временной блокировки IP).

**Q: Архив не создается, выдает ошибку**  
A: Возможные причины:
- Сайт блокирует боты Archive.ph
- Страница требует JavaScript
- Временные проблемы сервиса  
Попробуйте позже или используйте Conifer.

**Q: Можно ли архивировать PDF-файлы?**  
A: Archive.ph архивирует HTML-страницы. Для PDF лучше скачать файл напрямую.
