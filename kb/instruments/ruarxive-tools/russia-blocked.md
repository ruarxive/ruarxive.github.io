# russia-blocked (мониторинг госсайтов)

**russia-blocked** — ежемесячный мониторинг около 2 250 значимых российских госсайтов. Он проверяет две вещи: открываются ли сайты из-за рубежа и сохраняют ли их веб-архивы. Результаты публикуются на сайте [ruarxive.org/russia-blocked](https://ruarxive.org/russia-blocked/) на русском и английском языках, история архивов — с 2019 года.

- Репозиторий: [github.com/ruarxive/russia-blocked](https://github.com/ruarxive/russia-blocked) · Код — MIT, данные и материалы — CC BY 4.0 · Python (пакет `rublocked`, на PyPI не публикуется).
- Запущен 19.10.2026. Версий нет: изменения в CHANGELOG сгруппированы по датам.

> Цифры на этой странице взяты с сайта мониторинга 29.10.2026 (данные архивов обновлены 20.10.2026) и совпадают с файлом `domains.csv.gz` из открытых данных.

## Зачем

С 2022 года многие сайты федеральных органов власти, их территориальных органов, судов, избирательных комиссий и государственных информационных систем закрыты геоблокировкой, фильтрами DDoS и WAF. Зарубежные архивы, в первую очередь Internet Archive, не могут их сохранить. Обязательной архивации публичных госсайтов в России нет. Мониторинг каждый месяц измеряет масштаб проблемы и показывает, какие сайты видны только из российской сети. Предыстория — в кейсах [«Исчезновение сайтов государственных органов»](/kb/case-studies/government-websites-disappearing) и [«Исчезающие российские ресурсы»](/kb/case-studies/russia-resources-disappearing).

## Главные цифры, октябрь 2026

| Показатель | Значение |
| :--- | :--- |
| Работающие госсайты, которые не открываются для зарубежного краулера | **68 %** — 1 253 из 1 850 |
| Из них открываются из России, то есть закрыты именно для зарубежных посетителей | **65 %** — 814 из 1 253 |
| Сайты, которые Wayback Machine сохранял в 2021 году, без успешного снимка за последние 12 месяцев | **51 %** — 569 из 1 125 |
| Сайты той же группы, сохранённые с содержимым в 2026 году | **38 %** (проверено 1 123 из 1 125) |
| Сайты с сертификатом Russian Trusted CA, которому не доверяют браузеры и большинство краулеров | 36 |
| Истёкшие госдомены, перерегистрированные третьими лицами (казино, займы, клоны госсайтов) | 20 |

Сильнее всего различаются категории сайтов. Сайты избирательных комиссий закрыты для зарубежных посетителей почти все: 83 из 85 работающих открываются только из России. Суды, наоборот, почти все открыты: 180 из 185.

«Сохранён с содержимым» значит, что последний снимок года — настоящая страница, а не заглушка WAF, пустая страница или JS-оболочка.

## Что измеряется

| Источник | Что проверяется | Как часто |
| :--- | :--- | :--- |
| Проверка из-за рубежа | DNS, ASN и страна IP-адреса, TCP-порты 443 и 80, сертификат TLS и цепочка (включая Russian Trusted Root CA), тип ответа главной страницы (содержимое, JS-оболочка, проверка WAF, страница блокировки, пусто, ошибка), поставщик защиты, `robots.txt` | Ежемесячно |
| Та же проверка из российской сети | То же; отличает сайты, закрытые только для зарубежных посетителей, от сайтов, которые не работают ни у кого | Ежемесячно, сразу после зарубежной |
| WHOIS (`whois.tcinet.ru`) | Дата создания и тип владельца доменов .ru, .su и .рф; выявляет истёкшие госдомены, занятые третьими лицами | Раз в 90 дней |
| Wayback Machine (sparkline API) | Число снимков главной страницы по месяцам и лучший HTTP-статус месяца с 2019 года | Ежемесячно |
| Снимки Wayback Machine | Последний снимок главной страницы с HTTP 200 за каждый год, классифицированный тем же способом, что и живой ответ | Прошлые годы — один раз, текущий — ежемесячно |
| Common Crawl Host Index | Число страниц хоста в каждом краулинге по классам HTTP-статуса (краулинги с декабря 2021 по апрель 2025 года) | Один раз, новые краулинги — по мере появления |

В октябре 2026 года зарубежная проверка шла из Франкфурта-на-Майне (AS14061 DigitalOcean), проверка из России — из Москвы (AS50340 Selectel).

**Реестр.** 2 254 хоста выбраны из федеральной части базы [govdomains](https://github.com/infoculture/govdomains): около 7 700 хостов с типом, организацией, регионом и приоритетом архивации. В мониторинг вошли:

| Категория | Хостов |
| :--- | --: |
| Территориальные и региональные органы власти | 1 325 |
| Государственные информационные системы и порталы | 276 |
| Госучреждения, фонды и программы | 194 |
| Федеральные органы власти | 186 |
| Суды (регионального уровня и выше) | 185 |
| Избирательные комиссии субъектов | 88 |

Псевдонимы, неактивные и технические хосты (почта, тестовые серверы, личные кабинеты, API), языковые и мобильные версии в реестр не входят.

**Когорта 2021 года.** Доли по архивам считаются только по сайтам, у которых в 2021 году был хотя бы один снимок с HTTP 200 и которые до сих пор остаются госсайтами: домен работает и не перехвачен. В октябре 2026 года таких сайтов 1 125.

## Открытые данные

Раздел «Методика и данные» на сайте ссылается на файлы в `https://ruarxive.org/russia-blocked/data/download/`:

| Файл | Что внутри |
| :--- | :--- |
| `domains.csv.gz` | Одна строка на хост со всеми показателями: живой ответ из-за рубежа и из России, WHOIS, история Wayback по месяцам, качество снимков по годам, Common Crawl |
| `registry.csv` | Реестр хостов |
| `probe_<ГГГГ-ММ>.jsonl.gz`, `probe_ru_<ГГГГ-ММ>.jsonl.gz` | Сырые результаты проверок из-за рубежа и из России за месяц |
| `whois.jsonl.gz` | Ответы WHOIS |
| `wayback_snapshots.jsonl.gz` | Классификация снимков Wayback Machine |
| `commoncrawl_hosts.csv.gz` | Статистика хостов в Common Crawl |

Пример запроса в [DuckDB](https://duckdb.org/):

```sql
SELECT host, live_status, ru_live_status, abroad_vs_russia, wayback_last_200_month
FROM read_csv('https://ruarxive.org/russia-blocked/data/download/domains.csv.gz')
WHERE host = 'cikrf.ru';
-- cikrf.ru | timeout | ok | geoblock | 2023-12
```

Сайт ЦИК России из-за рубежа не отвечает, из России открывается, а последний успешный снимок его главной страницы в Wayback Machine сделан в декабре 2023 года.

## Как воспроизвести

Сайт можно собрать из данных, которые лежат в репозитории, без доступа к сети:

```bash
git clone https://github.com/ruarxive/russia-blocked.git
cd russia-blocked
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt

.venv/bin/python -m rublocked build             # собрать site/data/ из data/
python3 -m http.server 8791 --directory site    # открыть http://localhost:8791/
```

Ежемесячный цикл — команда `python -m rublocked monthly`. Она по очереди запускает `probe`, `whois`, `wayback`, `snapshots`, `commoncrawl` и `build`; шаги можно пропускать через `--skip`. Проверку отдельных хостов запускает `probe --hosts a.ru b.ru`. Зарубежная проверка отказывается работать из российской сети, а проверка из России — из зарубежной. Полный список команд и опций — в [README](https://github.com/ruarxive/russia-blocked#commands).

## Ограничения

- **Проверка из России идёт из одной сети дата-центра.** Сайт может закрыть и её или открываться из домашних сетей, но не из неё.
- **Архивные показатели — только по главной странице.** Даже если главная страница сохранена, большинства остальных страниц сайта в архиве может не быть.
- **Реестр отражает госдомены 2020–2022 годов.** Новые домены не отслеживаются, пока их не добавят в исходные списки.
