# ydiskarc (Yandex.Disk)

**ydiskarc** — утилита для скачивания публичных папок Яндекс.Диска без обязательного «сохранить на свой Диск».

Обычно, чтобы скачать папку целиком, Яндекс требует сохранения её на свой Диск (личное пространство). `ydiskarc` обходит это ограничение и скачивает содержимое публичной ссылки прямо на ваш компьютер, обходя публичный REST-эндпоинт `webdav.yandex.ru` или публичный listing-API.

- Репозиторий: [github.com/ruarxive/ydiskarc](https://github.com/ruarxive/ydiskarc) · Лицензия: MIT · Язык: Python

## Установка

```bash
pip install ydiskarc
```

Требуется Python 3.8+.

## Использование

```bash
ydiskarc https://disk.yandex.ru/d/AbCDeFgHiJkLm --output ./my-folder
```

### Опции

```bash
# Ограничить глубину рекурсии
ydiskarc https://disk.yandex.ru/d/AbCDeFgHiJkLm --output ./my-folder --max-depth 3

# Скачивать только файлы определённых типов
ydiskarc https://disk.yandex.ru/d/AbCDeFgHiJkLm --output ./my-folder --exts pdf,docx,zip

# Не качать файлы больше 100 МБ
ydiskarc https://disk.yandex.ru/d/AbCDeFgHiJkLm --output ./my-folder --max-size 100M

# Инкрементальный режим (пропускать уже скачанные по SHA-256)
ydiskarc https://disk.yandex.ru/d/AbCDeFgHiJkLm --output ./my-folder --resume
```

## Особенности

- **Поддерживает вложенные папки** — рекурсивно обходит всю структуру.
- **Качает каждый файл отдельно** — не требует создания ZIP-архива на стороне сервера, что снимает ограничение «файл слишком большой для упаковки».
- **Сохраняет исходную иерархию каталогов** в `--output`.
- **Полезно для архивации публичных датасетов** или коллекций документов (отчёты, фотоматериалы, научные данные), опубликованных государственными и общественными организациями.
- **Не требует авторизации** — работает с любыми публичными ссылками.

## Формат выходных данных

```
my-folder/
├── <структура папок как на Я.Диске>
└── …
```

Сохраняется оригинальная иерархия. Имена файлов — как в источнике. Дополнительно создаётся `manifest.jsonl` с SHA-256 и URL-ами — для верификации.

## Ограничения

- **Только публичные ссылки** — приватные папки, требующие авторизации, не скачиваются. Если у вас есть OAuth-токен Яндекса, рассмотрите [yadisk](https://github.com/yandex/yadisk) — полноценный Python-клиент к Я.Диску.
- **Зависимость от публичного API** — Яндекс может менять формат публичных ссылок. На момент версий `0.5+` поддерживается короткий URL `disk.yandex.ru/d/...`; ссылки `yadi.sk/d/...` также распознаются.
- **Скорость ограничена** серверами Яндекса. Утилита уважает `Retry-After` и не пытается «продавить» лимиты.
- **Большие файлы (>2 ГБ)** качаются одним потоком. Для сверхбольших файлов и параллельной загрузки нескольких объектов используйте специализированные утилиты (`aria2`).
- **Не работает с «запароленными» папками** — Яндекс не отдаёт контент без ввода пароля.

## Альтернативы

| Ситуация | Инструмент |
| :--- | :--- |
| Приватная папка с OAuth-токеном | [yadisk](https://github.com/yandex/yadisk) (sync) |
| Много мелких файлов, нужна параллельная загрузка | [aria2](https://aria2.github.io/) |
| Скачивание публичных коллекций по URL-паттернам | [filegetter](./filegetter) |
| Скачивание веб-страниц (не Я.Диск) | [wparc](./wparc), [wget](https://www.gnu.org/software/wget/) |

## Частые ошибки

- **`403 Forbidden`** — папка больше не публичная или требует пароль. Проверьте ссылку в браузере.
- **`404 Not Found`** — ссылка удалена или некорректна. Убедитесь, что используете полный `https://disk.yandex.ru/d/...`.
- **Медленная загрузка** — Яндекс ограничивает скорость на бесплатных аккаунтах. Используйте `--resume` для докачки.
