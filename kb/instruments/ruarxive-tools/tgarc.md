# tgarc (Telegram)

**tgarc** — инструмент команды Ruarxive для потоковой архивации публичных каналов и чатов Telegram. Использует официальный Telegram API (MTProto), что делает его совместимым с [Telegram Data Take-Out](/kb/instruments/data-take-out/dto-telegram), но добавляет инкрементальный режим, удобный CLI и формат вывода, согласованный с другими инструментами Ruarxive.

- Репозиторий: [github.com/ruarxive/tgarc](https://github.com/ruarxive/tgarc) · Лицензия: MIT · Язык: Python

## Основные возможности

- **Загрузка истории сообщений** в JSON/JSONL со всеми метаданными (автор, дата, реакции, репосты, ответы).
- **Скачивание медиафайлов** — фото, видео, документы, голосовые сообщения, стикеры.
- **Инкрементальный режим** — при повторном запуске скачиваются только новые сообщения, уже сохранённые пропускаются.
- **Официальный Telegram API (MTProto)** — без скрапинга веб-версии, что снижает риск бана и работает стабильнее.
- **Совместимый формат** — структура вывода согласована с другими инструментами Ruarxive.

## Установка

```bash
pip install tgarc
```

Требуется Python 3.8+.

## Настройка

Для работы нужны `api_id` и `api_hash` от [my.telegram.org](https://my.telegram.org). Это бесплатно: зарегистрируйте приложение, получите ключи и сохраните их локально.

Создайте файл `config.yaml`:

```yaml
api_id: 12345
api_hash: "0123456789abcdef0123456789abcdef"
phone: "+79001234567"
```

При первом запуске `tgarc` запросит код подтверждения из Telegram и создаст локальный `.session`-файл — это нормальный механизм авторизации MTProto.

## Использование

### Архивация канала

```bash
tgarc download --target durov --output ./durov_archive
```

Команда скачает все сообщения канала `@durov` (имя, @username или ID) и сохранит в `./durov_archive/`.

### Инкрементальное обновление

```bash
tgarc download --target durov --output ./durov_archive --incremental
```

При повторных запусках скачиваются только новые сообщения — это безопасно для регулярных задач по расписанию (cron / GitHub Actions).

### Только история без медиа

```bash
tgarc download --target durov --output ./durov_archive --no-media
```

Полезно для больших каналов, когда нужна только текстовая лента.

## Формат выходных данных

```
durov_archive/
├── messages.jsonl      # все сообщения (по одному JSON в строке)
├── media/              # папка с медиафайлами, имена — message_id
│   ├── 123.jpg
│   ├── 124.mp4
│   └── …
└── meta.json           # метаданные сессии: канал, даты, число сообщений
```

Структура одной записи в `messages.jsonl` соответствует объекту `Message` из Telegram API с добавленными полями `media_path` (если медиа сохранено) и `archive_meta` (служебные поля Ruarxive).

## Что дальше: что делать с архивом

После того как `tgarc` собрал данные, их удобно отдавать пользователям:

- Открыть [WARC/WACZ-конвертацию](/kb/users/open-warc) — если нужно упаковать в стандартный веб-формат.
- Построить статический сайт через [pywb](/kb/instruments/replay/pywb) или [metawarc replay](./metawarc).
- Применить [metawarc](./metawarc), если нужно извлечь метаданные и предоставить поиск.
- Процитировать архив по правилам [Цитирование архива Ruarxive](/kb/users/citation).

## Ограничения

- **Только публичные ресурсы** или каналы/чаты, в которых вы состоите. Приватные каналы, к которым у вас нет доступа, не архивируются.
- **Скорость скачивания медиа ограничена серверами Telegram** — большие каналы (миллионы сообщений, десятки гигабайт медиа) могут качаться часами.
- **Telegram-аккаунт может получить ограничения** при слишком агрессивной загрузке (Flood Wait). По умолчанию `tgarc` уважает эти ограничения, но при частых запусках стоит увеличить интервал.
- **Сообщения, удалённые до запуска архивации**, не восстановить — это не баг, а свойство Telegram.
- **Не работает с историй комментариев в каналах** (для этого нужен другой сценарий авторизации).

## Альтернативы и дополнения

- **[Telegram Data Take-Out](/kb/instruments/data-take-out/dto-telegram)** — официальный экспорт через UI Telegram, выдаёт JSON + HTML-дамп. Не инкрементальный, но авторитетный.
- **[tdl](/kb/instruments/tools/tdl)** — загрузчик медиа из Telegram, подходит для разовых выгрузок.
- **[metawarc](./metawarc)** — если архив уже в формате WARC и нужен поиск/анализ.
