# Как создать цифровой архив сайтов

Есть разные способы сохранения копии сайта: готовые онлайн-сервисы и приложения, а также утилиты командной строки (CLI).

> 🚨 **Экстренная ситуация?** Если времени мало, используйте [Быстрый старт: архивация за 5 минут](/kb/guides/quick-start-5min) или перейдите к разделу [Экстренные сценарии](#экстренные-сценарии) ниже.

---

## Быстрое сохранение отдельных страниц

Для сохранения одной или нескольких веб-страниц можно использовать онлайн-сервисы:

### Метод 1: Archive.org (Internet Archive)

Сохранить страницу можно через форму Save Page Now Интернет Архива на [этой странице](https://archive.org/web/). Пошагово:

1. Перейдите по ссылке: https://archive.org/web/.
2. Вставьте URL-адрес страницы, которую вы хотите заархивировать, в поле Save Page Now (внизу справа).
3. Нажмите на кнопку сохранения страницы (или клавишу Enter).
4. Подождите, пока страница будет обработана. После завершения появится URL-адрес заархивированной копии.

![Интерфейс Archive.org](/images/image3.png)

### Метод 2: Archive Today (archive.ph)

Сервис сохраняет текстовую и графическую копии веб-страницы и даёт ссылку на неизменную запись.

На главной странице сервиса можно ввести ссылку на веб-страницу, и она будет сохранена. Для сохранения страниц прямо из браузера есть [расширение](https://addons.mozilla.org/en-US/firefox/addon/archive-page) для Firefox.

![Интерфейс Archive Today](/images/image5.png)

> **Примечание**: эти методы подходят для отдельных страниц или небольших сайтов, а файл архива (WARC) вы на руки не получаете. Для полной архивации сайта используйте инструменты, описанные ниже.

## Сравнение инструментов: что выбрать?

| Инструмент | Скорость | Сложность | Файл WARC/WACZ | Когда использовать |
|-----------|---------|-----------|----------------|--------------------|
| **Save Page Now** | ⚡⚡⚡ минуты | ★☆☆ | Нет (копия хранится в Wayback Machine) | Одна страница, срочно, без установки |
| **Archive.ph** | ⚡⚡⚡ минуты | ★☆☆ | Нет | Одна страница, срочно, без установки |
| **HTTrack** | ⚡⚡ часы | ★★☆ | С версии 3.49-14, `--warc` | Локальная копия для просмотра, есть GUI |
| **Wget** | ⚡⚡ часы | ★★★ | Да, `--warc-file` | Автоматизация, тонкая настройка |
| **Wpull** | ⚡⚡ часы | ★★★ | Да | Wget-совместимый краулер на Python; не развивается |
| **Browsertrix** | ⚡ дольше | ★★☆ | Да, WARC и WACZ | Сайты на JavaScript, интерактивность |

**Быстрый выбор:**
- 📄 Одна статья или страница → [Archive.ph](/kb/instruments/tools/archive-ph) или Save Page Now
- 🏠 Небольшой сайт (до 1000 страниц) → Wget с WARC; HTTrack, если нужна только локальная копия
- 🏢 Большой или сложный сайт → Wget или [Browsertrix](/kb/instruments/tools/browsertrix)
- ⚡ Экстренно → Archive.ph и [экстренные сценарии](#экстренные-сценарии)

## Экстренные сценарии

### Когда счёт идёт на минуты

Если сайт может быть заблокирован или удалён в ближайшее время:

**1. Первые минуты — сохраните главные страницы через Archive.ph или Save Page Now:**

```text
Откройте archive.ph (или web.archive.org/save) и сохраните:
- главную страницу;
- страницу «О нас» / «About»;
- ключевые статьи и материалы;
- страницу контактов.
```

Подробнее: [Archive.ph: полное руководство](/kb/instruments/tools/archive-ph)

**2. Следующие минуты — запустите быструю архивацию всего сайта с записью WARC:**

```bash
wget --recursive --level=inf --page-requisites --adjust-extension --convert-links \
     --no-parent --wait=0.5 --limit-rate=200k \
     --warc-file=site-to-save --warc-cdx \
     https://site-to-save.com/
```

Рядом с локальным зеркалом появятся `site-to-save.warc.gz` и CDX-индекс. Именно WARC пригоден для веб-архива и просмотра в [pywb](/kb/instruments/replay/pywb) или [ReplayWeb.page](/kb/instruments/replay/replayweb-page); `--convert-links` меняет только локальные файлы, в WARC сохраняются исходные ответы. Вместо `--recursive --level=inf` можно написать `--mirror`, но с WARC wget отключает включённую в него проверку временных меток и выводит об этом предупреждение.

⚠️ **Важно**: эта команда может пропустить контент, который подгружается JavaScript. Для полноты используйте детальную настройку из [руководства по wget](/kb/guides/wget) или Browsertrix.

**3. Если есть час-два:**

Запустите [Browsertrix](/kb/instruments/tools/browsertrix) для сайтов с JavaScript или HTTrack, если нужна только локальная копия для просмотра (см. раздел [HTTrack](#httrack) ниже).

**Полный гайд по экстренной архивации:** [Экстренная архивация: когда счёт идёт на часы](/kb/guides/emergency-archiving)

## HTTrack

HTTrack — бесплатное (GPL) и простое в использовании приложение, которое загружает веб-сайт в локальный каталог: HTML-код страниц, изображения и другие файлы. Есть режим рекурсивной выгрузки всех страниц.

HTTrack сохраняет относительную структуру ссылок исходного сайта, так что копию можно открыть в браузере. Приложение имеет графический интерфейс и работает под Windows, macOS и Linux. Начиная с версии 3.49-14 (2026) HTTrack умеет писать WARC/1.1 и WACZ (`-%r`/`--warc`, `--warc-cdx`, `--wacz`); в более старых версиях WARC нет, и для веб-архива лучше подходят wget или Browsertrix. Подробнее — на странице [HTTrack](/kb/instruments/tools/httrack).

Для использования приложения не нужна специальная подготовка, но оно работает и из командной строки ([руководство пользователя](https://www.httrack.com/html/fcguide.html)). Подробнее — на странице [HTTrack](/kb/instruments/tools/httrack).

## Утилиты командной строки (CLI)

Классические утилиты командной строки для создания архива сайта — [Wget](https://www.gnu.org/software/wget/) и [Wpull](https://github.com/ArchiveTeam/wpull).

### Wget

Wget — свободная программа для получения файлов по HTTP, HTTPS и FTP. Это неинтерактивный инструмент командной строки, поэтому его легко вызывать из скриптов и терминала.

Возможности, полезные для зеркалирования сайтов:

- возобновление прерванной загрузки;
- рекурсивное зеркалирование каталогов;
- преобразование ссылок в загруженных документах в относительные, чтобы копию можно было открыть локально;
- поддержка cookies и постоянных HTTP-соединений;
- работа в фоновом режиме;
- запись WARC (`--warc-file`) начиная с версии 1.14.

Wget распространяется под лицензией GNU General Public License. Подробнее — [Использование утилиты wget](/kb/guides/wget).

### Wpull

Wpull — Wget-совместимый веб-загрузчик и краулер на Python с записью WARC. Краулер систематически обходит страницы сайта по ссылкам и сохраняет их.

Последний выпуск wpull на PyPI — 2.0.1 (2016 год); встроенная интеграция с PhantomJS устарела, поскольку сам PhantomJS больше не развивается. Для новых проектов чаще используют [grab-site](/kb/instruments/tools/grab-site), который построен на форке wpull. Подробнее — на странице [Wpull](/kb/instruments/tools/wpull).

![Commands Wpull](/images/image7.png)

У этих утилит есть режим рекурсивной выгрузки всех страниц, он задаётся опцией `-r`. В самом простом варианте достаточно выполнить команду, подобную этой:

```bash
wget -r -l inf --page-requisites --no-parent \
     --warc-file=example --wait=1 \
     https://example.com/
```

## Дальнейшие шаги

После успешной архивации сайта:

1. **Проверьте результат:** откройте WARC в [ReplayWeb.page](/kb/instruments/replay/replayweb-page) или сохранённые файлы в браузере.
2. **Создайте резервную копию:** скопируйте архив в несколько мест.
3. **Изучите продвинутые техники:** [Полное руководство по wget](/kb/guides/wget).
4. **Узнайте о форматах:** [WARC](/kb/instruments/file-formats/warc) и [WACZ](/kb/instruments/file-formats/wacz).
