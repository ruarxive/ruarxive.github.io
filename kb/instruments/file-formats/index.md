# Справочник форматов

Раздел содержит описания форматов файлов и стандартов метаданных, наиболее часто встречающихся в практике веб-архивации и долгосрочного цифрового сохранения. Раздел покрывает несколько классов задач:

*   **Контейнеры веб-архивов**: WARC, WACZ, индексы CDX/CDXJ, наследие MHTML.
*   **Метаданные и упаковка**: PREMIS, METS, BagIt.
*   **Форматы для специализированных архивов**: PDF/A (документы), MBOX (электронная почта), SIARD (реляционные базы данных), JP2 (изображения), IIIF (доставка изображений).
*   **Идентификация форматов**: инструменты (Siegfried, DROID, FIDO, Tika) и реестры (PRONOM, LC FDD, Wikidata).
