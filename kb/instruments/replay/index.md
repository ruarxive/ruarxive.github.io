# Воспроизведение архивов

После того как архив записан в формате WARC или WACZ, его нужно сделать
доступным для чтения. Просто открыть такой файл в браузере нельзя —
это специальный контейнер с HTTP-ответами. Для просмотра используют
так называемые **replay-системы**: они разворачивают локальный
веб-сервер, который отдаёт содержимое архива так, будто это живой сайт.

## Зачем нужны

*   **Проверка качества** записанного архива: сразу видно, какие страницы
    поломались, где не загрузились изображения.
*   **Доступ исследователям и читателям**: не нужно ставить себе
    спец-ПО, достаточно обычного браузера.
*   **Сохранение ссылочной целостности**: реплей-система переписывает
    ссылки так, чтобы навигация оставалась внутри архива.

## Когда использовать какой инструмент

*   **[ReplayWeb.page](/kb/instruments/replay/replayweb-page)** — браузерный replay без сервера,
    лучший выбор для разовых просмотров и отладки.
*   **[pywb](/kb/instruments/replay/pywb)** — основной серверный replay для публичных архивов;
    используется Internet Archive.
*   **[OpenWayback](/kb/instruments/replay/openwayback)** — Java-альтернатива pywb, нужна там,
    где уже есть JVM-инфраструктура.
*   **[IPWB](/kb/instruments/replay/ipwb)** — экспериментальный replay на IPFS, полезен для
    P2P-распространения.
*   **[warc2html](/kb/instruments/replay/warc2html)** — конвертация в одиночные HTML-файлы без
    сервера; подходит для отправки материалов в публикации.
