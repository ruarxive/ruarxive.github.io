# Курс по цифровой архивации

Курс по цифровой архивации — серия из четырёх лекций об основах сохранения цифрового наследия, веб-архивации и работе с цифровыми архивами.

## О курсе

Лекции подготовил Иван Бегтин — руководитель АНО «Инфокультура» и проекта «Национальный цифровой архив». Материалы курса использовались для занятий в одном из университетов ([#164](https://t.me/ruarxive/164)); на сайте они опубликованы в декабре 2025 года вместе с большим обновлением базы знаний ([#174](https://t.me/ruarxive/174)). Тексты страниц собраны из презентаций, поэтому в них много списков.

:::note
Цифры и списки инструментов в лекциях верны на дату чтения курса (на слайдах она не указана). Актуальные сведения — в разделах базы знаний, на которые ссылаются страницы лекций: подтверждённые цифры по коллекциям Ruarxive — на странице [«Статистика: снимок»](/kb/resources/stats-snapshot), описания инструментов — в разделе [«Инструменты»](/kb/instruments).
:::

Курс охватывает:

- введение в концепции цифрового сохранения;
- веб-архивацию и методы сохранения веб-контента;
- архивацию специализированных цифровых ресурсов;
- работу с Internet Archive.

## Лекции курса

### Лекция 1: Введение в цифровую архивацию

[DH.1. Введение в цифровую архивацию](/kb/course/dh1-introduction)

Основы цифровой архивации, понятия born-digital, цели и задачи цифрового сохранения, виды цифровых объектов, форматы файлов и этапы архивации. См. также: [форматы файлов](/kb/instruments/file-formats).

### Лекция 2: Веб-архивация

[DH.2. Веб-архивация](/kb/course/dh2-web-archiving)

Методы и инструменты веб-архивации, форматы веб-архивов, практические подходы к сохранению веб-контента. См. также: [как создать цифровой архив сайтов](/kb/instruments/howto-collect/make-copy-website), [похожие проекты](/kb/similar).

### Лекция 3: Архивация специализированных ресурсов

[DH.3. Архивация специализированных ресурсов](/kb/course/dh3-specialized-resources)

Архивация различных типов цифровых ресурсов: социальные сети, API, файловые хранилища, базы данных. См. также: [социальные сети](/kb/instruments/social-media), [Data Take-Out](/kb/instruments/data-take-out/data-take-out-main).

### Лекция 4: Интернет архив с точки зрения цифрового архивиста

[DH.4. Интернет архив с точки зрения цифрового архивиста](/kb/course/dh4-internet-archive)

Работа с Internet Archive, загрузка собственных архивов, альтернативы. См. также: [Internet Archive](/kb/similar/internet-archive).
