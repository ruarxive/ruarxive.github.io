# Как пользоваться архивами

Этот раздел — для **конечных пользователей** архивов: исследователей, журналистов, юристов,
студентов и просто интересующихся. Здесь объясняется, как найти нужный архив, открыть его
без программирования и корректно процитировать в своей работе.

## Типичные сценарии

- **Хочу посмотреть сайт, который уже не работает** — откройте [Как открыть WARC](/kb/users/open-warc).
- **Ищу конкретный сайт или раздел** — начните с таблицы сохранённых проектов:
  [preserved-projects-table](/kb/preserved-projects-table).
- **Готовлю научную работу и нужна ссылка на архив** —
  [Как цитировать архив Ruarxive](/kb/users/citation).
- **Хочу поделиться ссылкой на архив с коллегами** — в каталоге проектов
  ([Проекты](/kb/projects)) для каждой коллекции указаны прямые ссылки на скачивание.

## Чем отличается архив Ruarxive от Internet Archive?

| | Ruarxive | Internet Archive (Wayback Machine) |
|---|---|---|
| **Что хранит** | Полные снимки российских сайтов, Telegram, соцсетей | Глобальные снимки любых сайтов |
| **Доступ** | Прямые ссылки на скачивание архивов | Через веб-плеер или WARC |
| **Лицензия** | Большинство — CC-BY 4.0 с указанием авторства | Различается для каждого архива |
| **Полнота** | Полный сайт целиком (включая медиа) | Часто только HTML-страницы |

## Где искать архивы

1. **[Таблица сохранённых проектов (AirTable)](/kb/preserved-projects-table)** — основной каталог.
2. **Хаб открытых данных** [hubofdata.ru](http://hubofdata.ru/) — структурированные наборы данных.
3. **[Internet Archive](https://archive.org/details/@ruarxive)** — копия части коллекции.
4. **[Прямой CDN](https://cdn.ruarxive.org/public/)** — большие файлы для скачивания.
