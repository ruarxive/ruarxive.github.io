# Как пользоваться архивами

Этот раздел — для **конечных пользователей** архивов: исследователей, журналистов, юристов,
студентов и просто интересующихся. Здесь объясняется, как найти нужный архив, открыть его
без программирования и корректно процитировать в своей работе.

## Типичные сценарии

- **Хочу посмотреть сайт, который уже не работает** — откройте [Как открыть WARC](/kb/users/open-warc).
- **Ищу конкретный сайт или раздел** — начните с таблицы сохранённых проектов:
  [preserved-projects-table](/kb/preserved-projects-table).
- **Нужно достать из архива отдельную страницу или список URL** —
  [«Вскрытие» WARC](/kb/users/inspect-warc).
- **Архив очень большой (десятки и сотни ГБ)** — [Работа с большими WARC-файлами](/kb/users/large-warc).
- **Готовлю научную работу и нужна ссылка на архив** —
  [Как цитировать архив Ruarxive](/kb/users/citation).
- **Хочу поделиться ссылкой на архив с коллегами** — в каталоге проектов
  ([Проекты](/kb/projects)) для каждой коллекции указаны прямые ссылки на скачивание.

## Чем отличается архив Ruarxive от Internet Archive?

| | Ruarxive | Internet Archive (Wayback Machine) |
|---|---|---|
| **Что хранит** | Копии российских сайтов, Telegram-каналов, соцсетей | Снимки сайтов со всего мира |
| **Доступ** | Файлы архивов для скачивания (WARC, ZIP и др.) | Просмотр через веб-плеер Wayback Machine; часть коллекций — файлами |
| **Права** | Права на архивированные материалы принадлежат их правообладателям; лицензия CC BY 4.0 относится только к текстам сайта и базы знаний (см. [авторское право](/kb/legal/copyright)) | Условия различаются для разных коллекций |
| **Как собирается** | Целевые сборы конкретных сайтов и коллекций | Массовый обход веба и сохранение по запросам пользователей |

## Где искать архивы

1. **[Таблица сохранённых проектов](/kb/preserved-projects-table)** — основной каталог.
2. **Хаб открытых данных** [hubofdata.ru](http://hubofdata.ru/) — структурированные наборы данных.
3. **[Internet Archive](https://archive.org/details/@ruarxive)** — копия части коллекции.
4. **[Хранилище файлов](https://cdn.ruarxive.org/public/)** — большие файлы для скачивания; полный перечень — в [allarchives.csv](https://cdn.ruarxive.org/public/allarchives.csv).
