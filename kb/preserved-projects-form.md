# Запрос на архивацию ресурса

Сообщить, какой сайт или ресурс может исчезнуть, чтобы мы успели его сохранить, можно через [форму запроса на GitHub](https://github.com/ruarxive/ruarxive.github.io/issues/new?template=archive-request.yml). Короткая версия формы есть на [главной странице](/#request): в ней достаточно указать адрес и причину, остальные поля заполняются на GitHub.

Ключевые критерии включения в архив ([#16](https://t.me/ruarxive/16)):

1. Ресурс представляет общественную ценность — даже для небольшой группы людей.
2. У ресурса есть существенный риск исчезновения в ближайшее время — от дней до месяцев.

## Как подать запрос

1. Откройте [форму запроса](https://github.com/ruarxive/ruarxive.github.io/issues/new?template=archive-request.yml). Для этого нужен аккаунт на GitHub.
2. Укажите адрес ресурса, его тип, почему он ценен и какие есть признаки угрозы: ликвидация организации, блокировка, смена платформы, объявление о закрытии.
3. Выберите срочность и отправьте запрос.

Запросы публичные: их видят все, и по ним можно следить за статусом. Не указывайте в запросе данные, которые нельзя раскрывать. Уже поданные запросы — в [списке issues с меткой `archive-request`](https://github.com/ruarxive/ruarxive.github.io/issues?q=label%3Aarchive-request).

## Если нет аккаунта на GitHub или ресурс исчезнет в ближайшие часы

Пишите в Telegram-чат проекта [@ruarxivechat](https://t.me/ruarxivechat). Если ресурс нужно сохранить прямо сейчас, начните сами — см. [срочную архивацию](/kb/guides/emergency-archiving).

## Проверить, есть ли ресурс в архиве

Перед запросом проверьте, не сохранён ли ресурс раньше: поиск по реестру хранилища есть на [главной странице](/#search), список проектов — в [таблице сохранённых проектов](/kb/preserved-projects-table).
