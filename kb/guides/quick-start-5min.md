# Быстрый старт: архивация за 5 минут

> 🚨 **Экстренная ситуация?** Эта инструкция поможет сохранить важный контент за минимальное время, даже если вы никогда раньше не занимались архивацией.

## Когда использовать этот гайд

- Сайт или канал могут заблокировать в ближайшее время
- Вы узнали, что ресурс закроется завтра
- Контент активно удаляется прямо сейчас
- У вас нет времени разбираться в сложных инструментах

## ⚡ Что сохранить в первую очередь

Если времени мало, сохраняйте в таком порядке:

1. **Самое важное** - уникальные данные, которые нигде больше нет
2. **Текстовый контент** - статьи, посты (занимает мало места, быстро архивируется)
3. **Изображения** - фото, инфографика
4. **Видео и аудио** - если позволяет время и место

## 📄 Сохранить одну или несколько веб-страниц

### Способ 1: Internet Archive (1 минута) ✅ Основной

**Не требует установки!**

1. Откройте [web.archive.org/save](https://web.archive.org/save)
2. Вставьте URL в поле "Save Page Now"
3. Нажмите "Save Page"
4. Подождите результата
5. **Сохраните полученную ссылку!**

**Плюсы:** Надежное хранение, официальный архив  
**Минусы:** Может быть медленнее, иногда недоступен в РФ

**Расширение для браузера** (опционально):
- [Firefox](https://addons.mozilla.org/en-US/firefox/addon/archive-page/)
- [Chrome](https://chrome.google.com/webstore/search/archive%20page)

Теперь можно архивировать прямо из браузера одним кликом!

---

### Способ 2: Archive.ph (30 секунд) — только как дополнительная копия

1. Откройте [archive.ph](https://archive.ph)
2. Вставьте ссылку на страницу в поле
3. Нажмите "Save"
4. Дождитесь завершения (10-30 секунд)
5. Сохраните полученную ссылку

:::warning
В 2026 году оператор archive.today менял содержимое уже сохранённых снимков, а в России сервис может быть недоступен. Не используйте его как единственную копию и как доказательство. Подробнее — на странице [Archive.ph](/kb/instruments/tools/archive-ph).
:::

**Плюсы:** Мгновенно, не нужна регистрация, иногда сохраняет то, что не может Wayback Machine  
**Минусы:** Только отдельные страницы, не всегда корректно с JavaScript, снимки может изменить оператор, нет гарантий хранения

## 💬 Сохранить Telegram-канал или чат

### Telegram Desktop Export (2-5 минут)

**Что нужно:** Программа [Telegram Desktop](https://desktop.telegram.org/)

**Инструкция:**

1. Откройте Telegram Desktop
2. Перейдите в нужный канал/чат
3. Нажмите на название канала вверху → три точки ⋮ → **"Export chat history"**
4. **Настройте экспорт:**
   - ✅ Format: **JSON** или **HTML** (JSON лучше для обработки)
   - ✅ Limit: оставьте **All time** (вся история)
   - ✅ Media: отметьте что нужно (⚠️ видео займут много места!)
5. Выберите папку для сохранения
6. Нажмите **"Export"**
7. Дождитесь завершения (зависит от размера канала)

**Важно:** Экспорт работает только для:
- Публичных каналов
- Чатов, где вы участник
- Ваших личных сообщений

**Не работает:** Для чужих приватных чатов, секретных чатов

**Результат:** Папка с файлами `messages.html` (или `.json`) + медиафайлы

## 📱 Сохранить профиль в соцсетях

### Instagram (базовый способ, 2 минуты)

:::note
Instagram и Facebook принадлежат компании Meta Platforms Inc., деятельность которой по реализации этих продуктов признана в РФ экстремистской и запрещена.
:::

**Через браузер:**

1. Откройте профиль в Instagram (веб-версия)
2. Сделайте скриншоты важных постов (Win+Shift+S, Cmd+Shift+4 или другой инструмент скриншота)
3. Сохраните ссылки на посты в текстовый файл

**Официальный экспорт своих данных (до нескольких суток ожидания):**

1. Центр аккаунтов → Ваша информация и разрешения → [Скачать информацию](https://accountscenter.instagram.com/info_and_permissions/dyi/)
2. Выберите формат JSON или HTML
3. Ссылка на архив придёт на email, когда выгрузка будет готова

**Для срочной архивации:** Используйте скриншоты и ручное сохранение медиа

---

### Twitter/X (1 минута на текст)

**Быстрый способ:**

1. Откройте профиль
2. Прокрутите вниз, сохраняя важные твиты (Ctrl+S или скриншоты)
3. Для медиа: правая кнопка → "Сохранить изображение"

**Официальный экспорт:**
- Настройки → [Скачать архив данных](https://x.com/settings/download_your_data)
- Архив готовится от суток и дольше; ссылка придёт уведомлением

## 📂 Сохранить личные данные из сервисов (Data Takeout)

**Если у вас есть аккаунт и нужно сохранить СВОИ данные:**

### Google (5-10 минут настройки + ожидание)

1. Откройте [Google Takeout](https://takeout.google.com/)
2. Выберите сервисы (Gmail, Drive, Photos, YouTube и др.)
3. Нажмите "Следующий шаг"
4. Настройте формат архива (рекомендуем .zip, разделить на файлы по 10GB)
5. Нажмите "Создать экспорт"
6. Google пришлет ссылку на скачивание на email (может занять часы/дни)

**Срочно нужно?** Выберите только самые важные сервисы (Gmail, Drive)

---

### Facebook (настройка 2 минуты + ожидание)

1. Центр аккаунтов → Ваша информация и разрешения → [Скачать информацию](https://www.facebook.com/dyi)
2. Выберите профиль и данные для выгрузки
3. Формат: JSON (для обработки) или HTML (для просмотра)
4. Качество медиа: Высокое
5. "Создать файл"
6. Получите уведомление когда готово (обычно несколько часов)

Полный список сервисов: [Awesome Data Takeout](https://github.com/ivbeg/awesome-data-takeout)

## 🗂️ Сохранить целый сайт

### HTTrack (5 минут установка + время архивации)

**Для Windows/Mac/Linux, есть графический интерфейс**

1. Скачайте [HTTrack](https://www.httrack.com/)
2. Установите и запустите
3. **"Next"** → Введите название проекта → **"Next"**
4. Вставьте URL сайта в поле "Web Addresses"
5. **"Next"** → **"Finish"**
6. Дождитесь завершения

**Важно:** Не архивируйте сайты с большим количеством страниц (>10000) без настройки лимитов!

**Результат:** Папка с HTML-файлами, которые можно открыть в браузере

---

### Wget (для продвинутых, 1 минута)

**Если умеете работать с командной строкой:**

```bash
wget --mirror --page-requisites --adjust-extension --convert-links --no-parent \
     --wait=1 --random-wait \
     --warc-file=example-2026-10-12 --warc-cdx \
     https://example.com/
```

Команда делает офлайн-копию сайта в папке `example.com/` и одновременно записывает архивный файл `example-2026-10-12.warc.gz` с CDX-индексом. WARC-файл можно открыть в [ReplayWeb.page](https://replayweb.page/).

Подробнее: [Wget: сайт в WARC](/kb/guides/wget)

## ❓ Частые вопросы

**Q: Я сохранил в Archive.ph, но боюсь что сервис закроется. Что делать?**  
A: Сохраните ту же страницу в Wayback Machine (archive.org) или локально (SingleFile, ArchiveWeb.page). Снимок Archive.ph не должен быть единственной копией: оператор сервиса менял сохранённые снимки.

**Q: Telegram Desktop экспорт зависает на больших каналах**  
A: Попробуйте отключить загрузку видео и файлов, оставьте только текст и фото.

**Q: Сайт требует авторизацию, Archive.ph не сохраняет**  
A: Если у вас есть законный доступ к этим страницам, расширение [ArchiveWeb.page](https://webrecorder.net/archivewebpage/) запишет их в WARC/WACZ прямо в вашем браузере; можно также сделать скриншоты вручную. Не обходите авторизацию и не используйте чужие учётные записи — см. [Условия использования сервисов](/kb/legal/terms-of-service).

**Q: Куда передать архив после сохранения?**  
A: Напишите в [Telegram-чат Ruarxive](https://t.me/ruarxivechat), мы поможем с хранением.
